typedef struct CPMDCPropertySnapshot CPMDCPropertySnapshot

PROP-style property snapshot after a successful evaluation.

  • dipole[3]: OpenCPMD molecular dipole (electron Bohr) for the current geometry when dipole_count == 3

  • polarizability[9]: always zeros, with count 9; no build computes it

  • hessian[]: deprecated name of the nuclear gradient dE/dR packed as [n_atoms*3]. Use cpmdc_last_gradient() or cpmdc_session_last_gradient() instead. A full Hessian needs a dedicated PROP/Hessian run.

The fixed legacy array limits evaluations to 1365 atoms. libcpmdc rejects a larger system instead of truncating its gradient.

typedef struct CPMDCDipole CPMDCDipole

Molecular dipole after a successful evaluation.

valid is set only when OpenCPMD recomputed the dipole from the converged wavefunction for the current geometry. Values are electron Bohr.

typedef struct CPMDCStressTensor CPMDCStressTensor

Cartesian stress tensor after a successful PEF evaluation.

Layout is row-major [xx, xy, xz, yx, yy, yz, zx, zy, zz] in Hartree/Bohr^3 (OpenCPMD paiu/omega after totstr when cntltpres). valid is set only when that tensor was computed for a periodic cell. A positive cell volume is not enough: an isolated (cluster/Hockney) box leaves valid unset. Returns 0 when out->valid is set; -1 when stress was not computed.

CPMDC_API int cpmdc_set_params(const void* params_capnp, size_t params_capnp_size_bytes)

Apply CPMD method parameters from a Cap’n Proto message.

Callers do not need C setter functions for individual CPMD keywords. Build one CPMDParams message with top-level fields, structured inputSections, and literal inputBlocks, then pass its bytes to this function or to cpmdc_session_create().

Feature discovery mirrors the schema carriers: typed fields such as params.inputSections.cpmd.maxIter, params.inputSections.system.cell, params.inputSections.dft.hfxScreening, and params.inputSections.atoms.pseudopotentials; catalog sections such as catalog.section.VDW; and escape hatches such as params.inputSections.raw. The same serialized params buffer is accepted by cpmdc_calculate_result() for one-shot calls.

The call replaces the process-wide parameters that cpmdc_energy(), cpmdc_energy_gradient(), and cpmdc_energy_forces() evaluate with, and makes the process-wide calculator the active one, which the no-session cpmdc_last_* getters read. No CPMDCSession is modified.

Parameters:

params_capnp

Pointer to an unpacked flat CPMDParams message.

params_capnp_size_bytes

Size of params_capnp in bytes.

Returns:

0 on success, -1 on a NULL or empty buffer, a parse, render, or configuration failure, an embed that is not available, or an allocation failure. Failure text is cpmdc_last_error().

CPMDC_API int cpmdc_configure(const void* config_capnp, size_t config_capnp_size_bytes)

Apply configuration from a PotentialConfig message.

The cpmd union arm carries CPMDParams. With common unset, the arm is applied as given. A set common overlay (CommonMethodSpec) is merged over that arm. The arm bytes stay, and the deck renderers and the recorded settings apply the same precedence to the functional, cutoff, charge, and multiplicity lines cpmdc writes. A value a typed field sets beats the overlay, the overlay beats a schema default, and a typed dft or system section beats the top-level field. A field that is omitted or holds its schema default (functional BLYP, cutoff 70 Ry, charge 0 with hasCharge false, multiplicity 1) is unset, so it replaces neither the top-level arm value nor a merged overlay value; a typed system charge of 0 with hasCharge false is unset, and a non-zero charge or zero system.charge with system.hasCharge true is explicit. planewaveCutoffEv is in eV and is converted to Ry. spinMultiplicity 0 is unset, and any other value, an explicit singlet included, is set. An xcFunctionals list is mapped before that precedence, and an unmapped token is rejected for every arm functional. Those opaque carriers are rendered as given and are not read back into the recorded settings, so the carrier check runs for every set overlay field, whether or not a typed field also sets it, including zero charge with hasCharge true and an explicit singlet spinMultiplicity of 1: the overlay field is rejected when inputBlocks, a raw section, or a generic section opens the owning section (&DFT for xcFunctionals, &SYSTEM for the cutoff, charge, and multiplicity), when a set directive names DFT.FUNCTIONAL, SYSTEM.CUTOFF, SYSTEM.CHARGE, or SYSTEM.MULTIPLICITY, or when the directives list of the typed dft section holds FUNCTIONAL or that of the typed system section holds CUTOFF, CHARGE, or MULTIPLICITY. Without an overlay, a FUNCTIONAL directive in the typed dft section or a DFT.FUNCTIONAL set directive is rejected when the deck is rendered, because the rendered &DFT section already carries the functional. The same render rejects a CUTOFF, CHARGE, or MULTIPLICITY directive in the typed system section, and a SYSTEM.CUTOFF, SYSTEM.CHARGE, or SYSTEM.MULTIPLICITY set directive. CUTOFF is written on every deck, including the default 70 Ry. CHARGE is written only when it is not 0 and MULTIPLICITY only when it is greater than 1; an omitted line is the schema default the recorded configuration carries. Those directives are rejected for a default value and for any other value alike. A default leaves the directive as a value the recorded configuration does not carry, and any other value leaves two lines. The render does not keep one and drop the other. Fermi smearing is copied as FREE-ENERGY and TEMPERATURE ELECTRON when &CPMD sets no free-energy or electron-temperature control (including split TEMPERATURE and ELECTRON arguments in cpmd.directives or CPMD.TEMPERATURE set directives) and the arm has no raw or generic &CPMD block. vanDerWaalsS6 is copied into a vdwParams section whose s6 is unset. basisSet must be unset or "planewave". Next to the arm, kMesh, scfMaxIterations, scfEnergyToleranceEv, vanDerWaalsMethod, and relativityMethod are rejected, as are already-set smearing or s6, vanDerWaalsS6 without vdwParams, a non-plane-wave basisSet, and a negative or non-finite overlay scalar. With the arm unset, the overlay lowers to synthesized CPMDParams : functional, basis set, plane-wave cutoff, charge and hasCharge, multiplicity, SCF energy tolerance, MAXITER, the Monkhorst-Pack kMesh, smearing, and the van der Waals method and S6, the fields cpmdc_capabilities_result() lists. That overlay-only lowering also rejects vanDerWaalsS6 without vanDerWaalsMethod and a non-zero smearing.widthEv with kind = none. Overlay fields without a CPMD lowering are rejected. Every rejection leaves a cpmdc_last_error() that names its cause. An arm inputBlocks, inputSections, or directives list the merge cannot read is reported with the overlay field that needed it and the list, as in charge cannot merge: the cpmd arm has an invalid inputBlocks list.

A message with neither the arm nor an overlay applies nothing and returns

  1. An arm other than none and cpmd is rejected.

Returns:

0 on success, -1 on a NULL or empty buffer, a parse, lowering, or apply failure, or an embed that is not available.

CPMDC_API int cpmdc_bind_calculator(int ranks_per_calc)

Bind this rank to one CPMD calculator of ranks_per_calc ranks.

Collective on MPI_COMM_WORLD, before the first energy call. Each group is one CPMD calculator: its own communicator, its own wavefunction, the same deck.

On an OpenCPMD build the call starts MPI with MPI_Init when MPI is not running, before it looks at ranks_per_calc. No other build starts MPI: the reference build and the link stub return -1 without calling MPI.

How ranks are divided. A value of zero or less means the world size, which makes one group of every rank. Otherwise the world size must be a multiple of ranks_per_calc. There is no remainder group and no smaller last group: a world size that is not a multiple, or a value above the world size, is refused on every rank and nothing is split. The groups are consecutive blocks of world ranks. Group g holds the world ranks g * ranks_per_calc to (g + 1) * ranks_per_calc - 1, and there are world_size / ranks_per_calc groups. A rank is in group world_rank / ranks_per_calc (integer division) and has rank world_rank % ranks_per_calc inside it; the group’s first rank is its parent rank.

Returns the group index, or -1 when the world size is not a multiple of ranks_per_calc, MPI_Comm_split returns an error, or the library carries no CPMD backend (the reference build and the stub). Failure text is cpmdc_last_error().

The first call that is not refused splits MPI_COMM_WORLD with MPI_Comm_split. A later call does not split again, whether the communicator in use came from an earlier bind or from cpmdc_adopt_calculator_comm(). It checks its own ranks_per_calc as above and returns world_rank / ranks_per_calc for that value, which is the index of the group in use only when the value is the same. A later call whose value does not divide the world size, or is above it, returns -1 on every rank like the first call, and the split in use stays as it was.

CPMDC_API int cpmdc_adopt_calculator_comm(const void* comm, size_t comm_bytes, int ranks_per_calc)

Install a communicator the caller already split.

comm points at an MPI_Comm of comm_bytes bytes. Collective on that communicator. Does not call MPI_Init or MPI_Comm_split. Rank and size come from comm. When ranks_per_calc is greater than zero, that size must equal it. A mismatch returns -1 and cpmdc_last_error() names both numbers. Zero or less skips the size check. The group must be one aligned block of world ranks, starting at a multiple of the adopted size. Any other layout returns -1 on every rank of the group. The calculator index is the lowest world rank in that block divided by the size. Indices are unique when every group has the same size, which the same ranks_per_calc > 0 on every rank enforces. The handle is borrowed: the call does not use MPI_Comm_dup. It stores the caller’s communicator, and an OpenCPMD build also stores it as mp_comm_world. The caller keeps ownership and must not free the communicator until the last session is destroyed or a later adopt replaces it. An adopt after cpmdc_bind_calculator replaces the communicator that call split, and the caller of bind cannot free that one. A later call replaces the communicator when no live CPMDCSession has started an evaluation. A session that was created but has not evaluated does not block the call. If any rank of the group has a live session that has evaluated, every rank returns -1 and the stored communicator stays as it was. Returns the calculator index, or -1 when comm is null, comm_bytes is not the size of an MPI_Comm, comm is MPI_COMM_NULL, MPI is not initialized, or this build has no MPI. Failure text is cpmdc_last_error(). Call adopt, cpmdc_session_create, and cpmdc_session_destroy from one thread: g_evaluated_sessions and g_active_session are process globals, and OpenCPMD state is process-global too.

CPMDC_API int cpmdc_session_set_constant_cutoff(CPMDCSession* session, double cutoff_ry, double height_ry, double width_ry)

Evaluate the session with a constant-cutoff kinetic functional.

The session deck gains &SYSTEM CONSTANT CUTOFF, which replaces G^2 in the kinetic energy by G^2 + A [1 + erf((G^2 - E0) / sigma)] (Bernasconi et al., J. Phys. Chem. Solids 56, 501 (1995)). Energy and stress then belong to the constant cutoff E0 while the plane-wave basis keeps the deck’s cutoff, so the stress carries no Pulay stress and follows the energy across a change of cell. All values are Rydberg. cutoff_ry is E0; zero or less turns the functional off. height_ry is A; zero or less selects 50 times the deck’s cutoff. width_ry is sigma; zero or less selects E0 / 10. E0 + 2 sigma must not exceed the deck’s cutoff.

Returns:

0, or -1 when session is NULL, a value is not finite, the session has accepted a topology, E0 + 2 sigma exceeds the deck’s cutoff, the message also sets system.constantCutoff, or the message gives &SYSTEM as raw text. The session keeps its previous setting on failure, and the reason is cpmdc_last_error().

CPMDC_API int cpmdc_session_set_external_charges(CPMDCSession* session, size_t n_charges, const double* positions_ang, const double* charges_e, const double* widths_ang)

Set Gaussian-smeared MM point charges for the next session step.

Positions and Gaussian standard deviations are Angstrom; charges are in units of the elementary charge. widths_ang may be NULL, selecting CPMDC_EXTERNAL_CHARGE_WIDTH_ANG (default 0.30 Angstrom) for every charge. A count of zero clears the embedding. Repeating this call replaces the previous charge set and invalidates the geometry-result cache.

Every charge and position must be finite, and every width must be finite and at least 1e-12 Angstrom. A narrower width is refused with CPMDC_ERROR_INVALID_ARGUMENT and leaves the previous charge set in place, because the force terms scale as 1 / sigma^4 and overflow to NaN for much narrower Gaussians. The same lower bound applies to CPMDC_EXTERNAL_CHARGE_WIDTH_ANG.

The interaction kernel is erf(r / (sqrt(2) sigma)) / r, evaluated from its closed form for r / sigma above 1/8 and from a Taylor series in (r / sigma)^2 through (r / sigma)^14 below it, so a charge at an ion position gives a finite energy and force. Only isolated systems are supported. A periodic cell, or a deck that is not an isolated system, fails with CPMDC_ERROR_UNSUPPORTED_PERIODIC_EMBEDDING on every evaluation path.

CPMDC_API int cpmdc_session_select_orbitals(CPMDCSession* session, long long key)

Name the calculation the next evaluations of this session belong to.

The process stores the converged orbitals of one SCF. With a key named, those orbitals are kept per key: an evaluation under a key starts from the orbitals the last converged evaluation under the same key left, and a key that has none yet starts from the orbitals already stored. Of the stored orbitals of every key, the ones that converged nearest to the new geometry start the SCF, and only within CPMDC_WARM_RMSD (root-mean- square distance per atom, default 0.15 Angstrom); farther, the deck’s guess starts it. A host that runs several calculations on one calculator, the images of a band or the beads of a ring polymer, names each by a stable key, so each starts from its own previous geometry instead of from its neighbour’s. Every rank of a calculator names the same key before the same evaluation. The call records the key. The evaluation applies it, so a key that is named and then replaced before an evaluation does not park orbitals. A key also keeps its own EXTRAPOLATE WFN ring, so switching keys preserves each trajectory’s predictor history. CPMDC_ORBITAL_SLOT_LIMIT, a positive integer, is the most parked orbital copies plus populated extrapolation-ring entries, including the selected key’s entries, on an OpenCPMD build. The reference build stores neither orbitals nor rings and counts parked keys only. An evaluation that would add another copy past that limit fails, cpmdc_last_error() names the variable, and every stored copy and the selected key are left unchanged. Unset storage is unbounded. A basis change clears every key’s orbitals and history. A session that never names a key keeps the single process history exactly as the unkeyed route does. An unkeyed evaluation after a keyed one empties the history, and so does destroying the session that evaluated last.

Returns:

0, or -1 when session is NULL.

CPMDC_API int cpmdc_session_copy_orbitals(CPMDCSession* session, long long from_key, long long to_key)

Copy stored orbitals from one key to another in this session.

The call duplicates the converged orbitals from_key held at copy time, and the geometry they converged at, into to_key, replacing whatever to_key already held. The selected key is unchanged. If to_key is the selected key, its live store is replaced immediately; otherwise the live store is unchanged. Selecting to_key afterwards starts from that copy. A donor whose last pass did not converge is refused, including a parked copy and a copy onto the same key. A copy that would park a new key past CPMDC_ORBITAL_SLOT_LIMIT returns -1, cpmdc_last_error() names that variable, and the copies already stored stay. The reference build has no orbital store and returns 0, unless the limit is set to a value that is not a positive integer, which fails the call. The link stub returns -1, including a same key copy. Every rank of a calculator names the same keys, the same rule cpmdc_session_select_orbitals() has.

Returns:

0, or -1 when session is NULL, no evaluation has run yet, from_key has no converged orbitals, or the copy cannot be completed. The reason is cpmdc_last_error().

CPMDC_API int cpmdc_session_calculate_au(CPMDCSession* session, int n_atoms, const double* positions_bohr, const int* atomic_numbers, const double* cell_bohr, double* energy_h, double* forces_h_bohr, double* virial_h)

Compute energy, forces, and virial for one step in atomic units.

The plain-array form of cpmdc_session_calculate_result() for callers without a Cap’n Proto encoder (C, Fortran BIND(C), LAMMPS plugins, i-PI clients). The arguments come in the order of cpmdc_session_energy_forces() : atom count, positions, atomic numbers. Every quantity is atomic units.

session comes from cpmdc_session_create() or cpmdc_session_create_from_config() and is not yet destroyed. Every pointer is borrowed for the call: the session copies what it keeps, and the caller allocates and owns every buffer. The call is not thread-safe, and with OpenCPMD linked it is collective on the calculator communicator, so every rank of a calculator passes the same arguments in the same order. The stub build returns -1.

  • positions_bohr : 3 * n_atoms doubles, Bohr, atom-major row-major (x0 y0 z0 x1 ...).

  • atomic_numbers : n_atoms values in 1..118. A value outside that range fails the call.

  • cell_bohr : NULL for a step without a cell, or 9 doubles, Bohr, row-major with one lattice vector per row (a_x a_y a_z b_x ...), the layout of ForceInput.box. A cell with a non-zero entry replaces the deck’s CELL. NULL and an all-zero cell give the deck the same treatment: its CELL stays, or a 12 Angstrom cube when it has none. The call still keeps an all-zero cell as a step with a cell, which is not a step without one. A NULL cell and an all-zero cell are different steps for the repeat match below. With OpenCPMD linked, stored orbitals follow the same rule: a step with an all-zero cell can start from them only when the latched step had a cell equal to it, never when it had none, and a NULL step only when the latched step had none.

  • energy_h : receives the total energy, Hartree.

  • forces_h_bohr : receives 3 * n_atoms forces, Hartree/Bohr, laid out as the positions. Forces are the negative nuclear gradient, -dE/dR. On an isolated OpenCPMD deck the atoms are first moved rigidly so that their centre of mass is the middle of the deck’s cell along every non-periodic lattice vector, and the net force of the grid is removed (CPMDC_RECENTER, default mass), so the energy and forces do not depend on where the caller puts the atoms. The caller’s positions are not changed.

  • virial_h : NULL, or receives 9 doubles, Hartree, row-major, the virial -dE/d(strain). It is |det(cell)| times the stress of cpmdc_session_last_stress(), whose sign is -(1/V) dE/d(strain). ASE’s stress is -virial / V; i-PI takes this virial as it is. The virial is zero when cell_bohr is NULL or all zero, and when no stress was computed (an isolated deck or CPMDC_STRESS=0); cpmdc_session_last_stress() tells those apart.

The step is the cpmdc_session_calculate_result() step of a ForceInput with lengthUnit = "bohr", energyUnit = "hartree", and the same positions, atomic numbers, and box (empty for cell_bohr == NULL), and gives the same bits. session_accept_topology fixes the topology as soon as an evaluation call passes its argument checks, even when the evaluation then fails, and it is never rolled back. A repeat of the stored positions and cell returns the stored result.

A repeat matches the stored step atom by atom, in any atom order, when the element agrees and every position component and every cell component agrees within 1e-8 Angstrom, and when both steps have a cell or both have none. A NULL cell and an all-zero cell are different steps for that match. A repeat does not evaluate: it copies the stored forces into the caller’s atom order, returns the stored energy, and forms the virial from the stress that evaluation stored.

Returns:

0 on success; -1 on a NULL session, positions_bohr, atomic_numbers, energy_h, or forces_h_bohr; n_atoms outside 1.. INT_MAX / 3; an atomic number outside 1..118; a change of the atom count or of the element counts after the topology is fixed; an allocation failure; or a failed evaluation. Failure text is cpmdc_last_error(), empty after a success. On -1 energy_h and virial_h are not written, and the contents of forces_h_bohr are unspecified.

int cpmdc_pwscale_eval(const cpmdc_pwscale_problem* prob, const double* positions_bohr, const int* atomic_numbers, double* forces_h_bohr, int nthreads, int dist, cpmdc_pwscale_stats* stats)

Evaluate the scaffold on one rank.

dist selects the split: plane waves, or atoms. nthreads is the OpenMP team size. One thread is the serial loop. Wall time covers scratch allocation, the arithmetic, and the ordered sum. int cpmdc_pwscale_eval_mpi(const cpmdc_pwscale_problem* prob, const double* positions_bohr, const int* atomic_numbers, double* forces_h_bohr, int nthreads, int dist, cpmdc_pwscale_stats* stats, const void* comm, size_t comm_bytes)

Evaluate the scaffold on every rank of one communicator.

Every rank passes the same problem. Every rank receives every rank’s partial and sums them in rank order. nthreads is the team inside a rank. comm NULL selects MPI_COMM_WORLD. A build without MPI returns CPMDC_PWSCALE_ERR_NOMPI. seconds runs from the entry of the bound call to the end of the rank-ordered sum, the Allgather included. The bind step of this call is not timed. Each rank holds (ranks + 1) * (3 * natoms + 4) doubles for the sum.

int cpmdc_restart_write_path(const CPMDCRestart* file, const char* path, char* err, size_t err_cap)

Write the image to a filesystem path.

The bytes land in a temporary file in the same directory, which is flushed and synced to disk before it replaces path by rename (MoveFileEx with MOVEFILE_REPLACE_EXISTING on Windows). A reader sees the previous file or the finished one. On POSIX the directory is synced after the rename, so the new name survives a crash.

On POSIX, when path is a symbolic link the link stays and the file it names is replaced, in that file’s directory: the temporary file and the directory sync are there too. A link whose target is absent gets the new file at that target. A replaced file keeps its permission bits, and a new file is created with mode 0666 under the umask.

A failure before the rename removes the temporary file and leaves path untouched. A failure to sync the directory returns -1 with path already holding the new image.

Parameters:

file

Image to write.

path

Destination path.

err

Diagnostic buffer. May be NULL.

err_cap

Capacity of err, including the terminating NUL.

Returns:

0 on success, -1 with the reason in err.
