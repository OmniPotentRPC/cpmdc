Stored orbitals start an SCF only when they converged within `CPMDC_WARM_RMSD` (root-mean-square distance per atom, default 0.15 Angstrom) of the new geometry; the nearest stored copy of any key is taken, and beyond the limit the deck's guess starts the SCF. On the Si3N4 OCI-NEB a far key had taken 143 to 530 SCF steps from another image's orbitals where the guess takes 37 to 63. `CPMDC_SCF_STEPS=1` also prints where each SCF started.
