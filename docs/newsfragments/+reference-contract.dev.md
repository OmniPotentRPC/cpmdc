The `reference-contract` test fails when a public function, type, enum constant, or macro of `cpmdc.h`, `cpmdc_features.h`, or `cpmdc_restart.h` is missing from the C ABI reference (a function needs its parameter list in a table row), when a module of `python/cpmdc` has no `__all__` or leaves a public function or class out of it, when a name in `__all__` or a public member of an exported class, such as `CPMDCCalculator.ignored_changes`, is missing from the Python reference, or when the README or an Org page names a `cpmdc_` identifier that no public header declares.
