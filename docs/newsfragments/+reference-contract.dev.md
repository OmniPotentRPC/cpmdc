The `reference-contract` test fails when a public function, type, enum constant, or macro of `cpmdc.h`, `cpmdc_features.h`, or `cpmdc_restart.h` is missing from the C ABI reference (a function needs its parameter list in a table row), when a public Python name outside `cpmdc.ase` is missing from the Python reference, or when the README or an Org page names a `cpmdc_` identifier that no public header declares.
