`CPMDCCalculator`, `cpmdc-ipi`, `cpmdc-ipi-c`, and native deck rendering now use the same float64 rank cutoff for periodic cells and preserve every representable cell component in generated CPMD input. Cells whose volume would underflow, duplicate or invalid i-PI `batch_size` values, non-UTF-8 `INIT` data, and negative or non-finite connection waits now report their cause instead of being treated as an ordinary request.
