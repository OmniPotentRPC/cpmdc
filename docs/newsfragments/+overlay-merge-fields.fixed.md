Merging a `common` overlay (`CommonMethodSpec`) into a native `cpmd` arm in `cpmdc_configure()`, `cpmdc_session_create_from_config()`, `cpmdc_session_configure()`, and `cpmdc_calculate_result_from_config()` now validates `basisSet` (`"planewave"` or unset), lowers Fermi `smearing` into `&CPMD` when free-energy controls are absent, copies `vanDerWaalsS6` into a `vdwParams` section when `s6` is unset, and rejects conflicting, unmappable, or out-of-range overlay values through `cpmdc_last_error()`. Overlay-only lowering also rejects `vanDerWaalsS6` without `vanDerWaalsMethod` and non-zero `smearing.widthEv` with `kind = none`. An `xcFunctionals` list is mapped before arm-wins precedence, so an unmapped token is rejected for every arm functional. Schema defaults on typed `system` (`cutOffRy` 70 Ry, `charge` 0, `multiplicity` 1) and `dft` (`functional` `BLYP`) sections are treated as unset across effective config, embed apply, cluster HFX solver selection, and deck rendering, so omitted section fields keep explicit root `CPMDParams` values and allow merged overlay scalars to reach the deck while explicit non-default section values win. The carrier check runs for every set overlay field, whether or not a typed field also sets it: the overlay field is rejected when `inputBlocks`, a raw section, or a generic section opens `&DFT` or `&SYSTEM`, when a set directive names `DFT.FUNCTIONAL`, `SYSTEM.CUTOFF`, `SYSTEM.CHARGE`, or `SYSTEM.MULTIPLICITY`, or when a typed section directive renders the same setting, including a `FUNCTIONAL` directive and a `MULTIPLICITY` directive. Those carriers stay in the rendered deck and are not read back into the recorded functional, cutoff, charge, or multiplicity. A `spinMultiplicity` of 0 is unset, and any other value, an explicit singlet included, is merged and checked like the other overlay scalars, so a singlet next to an `&SYSTEM` carrier is rejected. Smearing conflict detection also handles split `TEMPERATURE` and `ELECTRON` arguments in `cpmd.directives` and `CPMD.TEMPERATURE` set directives. Every rejection names its cause in `cpmdc_last_error()`, and an arm `inputBlocks`, `inputSections`, or `directives` list that cannot be read is reported as `<field> cannot merge: the cpmd arm has an invalid <list> list`.
