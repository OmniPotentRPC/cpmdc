Merging a `common` overlay (`CommonMethodSpec`) into a native `cpmd` arm in `cpmdc_configure()`, `cpmdc_session_create_from_config()`, `cpmdc_session_configure()`, and `cpmdc_calculate_result_from_config()` now validates `basisSet` (`"planewave"` or unset), lowers Fermi `smearing` into `&CPMD` when free-energy controls are absent, copies `vanDerWaalsS6` into a `vdwParams` section when `s6` is unset, and rejects conflicting, unmappable, or out-of-range overlay values through `cpmdc_last_error()`. Overlay-only lowering also rejects `vanDerWaalsS6` without `vanDerWaalsMethod` and non-zero `smearing.widthEv` with `kind = none`. An `xcFunctionals` list is mapped before arm-wins precedence, so an unmapped token is rejected for every arm functional. Schema defaults on typed `system` (`cutOffRy` 70 Ry, `charge` 0, `multiplicity` 1) and `dft` (`functional` `BLYP`) sections are treated as unset across effective config, embed apply, cluster HFX solver selection, and deck rendering, so omitted section fields keep explicit root `CPMDParams` values and allow merged overlay scalars to reach the deck while explicit non-default section values win. An explicit overlay scalar (including singlet `spinMultiplicity` 1) that would fill a schema default is rejected when `inputBlocks`, a raw section, or a generic section opens `&DFT` or `&SYSTEM`, when a set directive names `DFT.FUNCTIONAL`, `SYSTEM.CUTOFF`, `SYSTEM.CHARGE`, or `SYSTEM.MULTIPLICITY`, or when typed `dft.directives` or `system.directives` carries that keyword. Smearing conflict detection also handles split `TEMPERATURE` and `ELECTRON` arguments in `cpmd.directives` and `CPMD.TEMPERATURE` set directives.
