`schema/inventory/surface_map_abi.txt` is generated by `scripts/abi_inventory.py` from the symbols `libcpmdc` exports and the declarations in `include/cpmdc.h` and `include/cpmdc_features.h`; it lists the 44 public functions, which are all the library exports.
The `c-abi-inventory` Meson test and the CI stub job fail when the file is stale, when a public declaration lacks `CPMDC_API` or is not exported, or when the library exports any other symbol; `meson compile -C build abi-inventory` regenerates it.
