`schema/inventory/surface_map_abi.txt` is generated by `scripts/abi_inventory.py` from the symbols `libcpmdc` exports and the declarations in `include/cpmdc.h` and `include/cpmdc_features.h`; it now lists all 44 public functions and the 56 internal exports.
The `c-abi-inventory` Meson test and the CI stub job fail when the file is stale, when a public declaration is not exported, or when an exported `cpmdc_` symbol is neither declared publicly nor listed in `scripts/abi_internal_exports.txt`; `meson compile -C build abi-inventory` regenerates it.
