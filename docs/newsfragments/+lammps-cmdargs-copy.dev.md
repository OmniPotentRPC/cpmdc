The LAMMPS tests, `tests/python/lammps_case.py`, and `bench/lammps_routes.py` hand every LAMMPS instance a fresh copy of the shared command-line list, because the `lammps` Python module of the 2Aug2023 stable series inserts its program name into the list it is given, so the second instance of a process started with `lammps lammps -log none` and stopped before the first command. The standalone `lammps_case.py` driver also calls `finalize()` after `close()`, so that each rank of an `mpiexec` run leaves MPI cleanly with that module.
