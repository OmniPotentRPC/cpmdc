`cpmdc_restart_write_path()`, and with it `cpmdc-restart patch-positions`, replaces a `RESTART` file in one step. The image goes to a temporary file in the destination's directory, which is flushed and synced with `fsync`, renamed over the destination, and followed by an `fsync` of the directory; on Windows `_commit` and `MoveFileEx` with `MOVEFILE_REPLACE_EXISTING` and `MOVEFILE_WRITE_THROUGH` do the same. A reader sees the previous file or the finished one, a failure before the rename removes the temporary file and leaves the old `RESTART` in place, and the published file keeps the mode `fopen` gave it. Before, the writer truncated the destination first, so a reader or a crash during the write saw a partial file.
