The embed enters the pseudopotential library only for the `&ATOMS` read, exports the library's absolute path in `CPMD_PP_LIBRARY_PATH` and `PP_LIBRARY_PATH` (and in `CPMDC_PSEUDO_DIR` when the caller gave a relative one), and every evaluation entry point returns the process to the host directory before it returns. A CPMD stop while the deck is parsed writes `LocalError` into the host directory, and a later call from another directory still finds the library.
