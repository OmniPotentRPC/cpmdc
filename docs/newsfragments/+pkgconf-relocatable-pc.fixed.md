The installed `cpmdc.pc`, `cpmdc-restart.pc`, and `libcp2k.pc` files now derive `includedir` and `libdir` from `${pcfiledir}` before setting `prefix`, so consumers compile and link after an installation prefix is moved under both plain `pkg-config` and `pkgconf --define-prefix`. `cpmdc-installed-package-consumer` now moves the installed prefix and runs the `cpmdc`, `cpmdc-restart`, `libcp2k`, `cpmdc-ipi-c`, and CMake consumer checks against the relocated prefix under both `pkg-config` modes.
