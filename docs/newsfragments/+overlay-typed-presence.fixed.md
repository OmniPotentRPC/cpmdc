The functional, cutoff, charge, and multiplicity are resolved once, and `cpmdc_params_render_input_deck_ov()`, `cpmdc_params_render_deck_with_geometry_ov()`, `cpmdc_params_effective_config_ov()`, and the configuration the embed records all read that result, so a typed `dft` section naming `BLYP` next to an overlay `xcFunctionals` no longer writes `FUNCTIONAL BLYP` while recording the overlay functional. A value a typed field sets beats the overlay, the overlay beats a schema default, a typed section beats the top-level field, and the overlay cutoff is converted from eV to Ry before it is written.
