`cpmdc_last_error_code()` returns a `CPMDCErrorCode` for the last failure of the calling thread: invalid argument, unavailable backend, periodic embedding, failed evaluation, or a deck `EXTERNAL POTENTIAL` combined with session charges. Python raises the matching `CPMDCError` subclass with the code in `CPMDCError.code`, and a library that predates the symbol still works with code 0. A deck `EXTERNAL POTENTIAL` or `EXTERNAL POTENTIAL ADD` combined with session charges is refused with its own code instead of a generic failure.
