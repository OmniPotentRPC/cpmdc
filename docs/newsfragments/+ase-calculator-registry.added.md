`cpmdc.ase` registers `CPMDCCalculator` under `"cpmdc"` with `ase.calculators.calculator.register_calculator_class` (idempotently, so `get_calculator_class("cpmdc")` returns `CPMDCCalculator` and repeated registration does not raise), and `pyproject.toml` exposes `cpmdc = "cpmdc.ase"` in the `ase.plugins` entry-point group with a guarded `__ase_plugins__` `CalculatorPlugin` that is a no-op on ASE versions without the v4 plugin API.
