Every public name of cpmdc has one entry on this page: the exported C functions, the C types and constants, the Python names that each module lists in ~__all__~ with the public members of its classes, and the properties and parameters of the ASE calculator. Each entry states the units, the array layout or shape, who owns every pointer or object, what threads and MPI ranks may do, every return or error code with the Python exception it becomes, and the defaults.

The ~reference-audit~ test keeps the page and the code together. It reads the C names from the headers that ~meson install~ places, and the Python names from the imported package. It fails when a public name has no entry, when an entry names a symbol that does not exist, when a Python signature row differs from the one ~inspect~ reports, and when a row that must say something is empty. The other reference pages explain the behaviour at more length: the [[file:c-abi.org][C ABI reference]], the [[file:python.org][Python reference]], the [[file:gromacs.org][GROMACS page]] and the [[file:lammps.org][LAMMPS page]].

* Conventions

Units are stated in every entry. The array calls of the C library take positions in Angstrom and give Hartree and Hartree/Bohr. ~cpmdc_session_calculate_au()~ takes Bohr and gives Hartree, Hartree/Bohr and a virial ~-dE/d(strain)~ in Hartree. The stress of the C library has the OpenCPMD sign ~-(1/V) dE/d(strain)~ in Hartree/Bohr^3, which is the opposite of ASE's. The Python ~Potential~ and the ASE calculator return eV, eV/Angstrom and eV/Angstrom^3 with the ASE sign. ~Session~ returns the atomic units of the C ABI.

Arrays are C order and atom-major: ~x0 y0 z0 x1 ...~. A matrix is row-major with one lattice vector per row, except in the i-PI wire, where the cell holds the lattice vectors as columns. Atomic numbers are ~int~ values in 1..118.

Threads: the C library keeps the active calculator, its stored orbitals and the OpenCPMD state in process globals, so evaluation, configuration and session calls are used by one thread at a time. The error text of ~cpmdc_last_error()~ is per thread. The snapshot readers share the globals of the evaluation. The static restart library has no global state.

MPI: a build compiled without MPI never calls it. A reference build compiled
with MPI calls ~MPI_Allreduce~ from ~rank_consensus_all~ on the session cache
path when ~CPMDC_RANK_CONSENSUS~ is ~1~ and MPI is initialized, so every rank
agrees before a stored result is returned. The same setting runs the
collectives in ~rank_consensus~ on an evaluation. An OpenCPMD build also runs
the evaluation as a collective on the calculator communicator, so every rank
of a calculator makes the same call in the same order. The Python package
never calls MPI itself; ~cpmdc.lammps.FixExternal~ gathers on rank 0 with
~mpi4py~.

Errors: a C call reports failure in the return value and writes the reason to ~cpmdc_last_error()~ of the calling thread. The Python package turns every such failure into ~cpmdc.CPMDCError~, and it raises ~ValueError~ or ~TypeError~ for an argument that it can reject before the call.

*** ~cpmdc_adopt_calculator_comm~

** Configuration and one-shot arrays without a session

These calls use the process-wide state.
An evaluation is cold when the process has no stored basis or the basis
differs, and warm when the basis matches.

* ASE properties

The properties ~CPMDCCalculator~ implements, in ASE units.

| Property | Units | Shape and dtype | Sign and convention | Raises |
|--------+--------+--------+--------+--------|
| energy | eV | scalar ~float~ | The potential energy of the step; the library separates no electronic entropy. | ~CalculationFailed~ when the library rejects the step or returns a non-finite value; ~ValueError~ for invalid atoms. |
| free_energy | eV | scalar ~float~ | Equal to ~energy~. | As for ~energy~. |
| forces | eV/Angstrom | (N, 3) ~float64~ array | The negative nuclear gradient ~-dE/dR~. | As for ~energy~. |
| stress | eV/Angstrom^3 | (6,) ~float64~ array in Voigt order xx, yy, zz, yz, xz, xy | ASE sign, ~(1/V) dE/d(strain)~, the opposite of the OpenCPMD sign; shear parts are averaged. | ~PropertyNotImplementedError~ for a cluster (every ~pbc~ flag false) or for a step the library gave no stress for; ~ValueError~ for a partly periodic cell. |
