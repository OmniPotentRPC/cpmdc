* Read by libcpmdc at run time

| Variable | Read in | Effect |
|----------+---------+--------|
| ~CPMDC_PSEUDO_DIR~ | ~src/cpmd_embed_c_api.F90~, first call of an OpenCPMD session | directory holding the pseudopotential files named in the deck; ~cpmdc~ changes into it while CPMD reads them, then leaves it before CPMD writes output files |
| ~CPMD_PP_LIBRARY_PATH~ | same place, when ~CPMDC_PSEUDO_DIR~ is unset | fallback for the same directory |
| ~CPMDC_DECK_OUT~ | ~src/cpmdc.c~, each time a message is rendered | file that receives the rendered method deck; each write replaces the last |
| ~CPMDC_STRESS~ | ~src/cpmd_embed_c_api.F90~, each evaluation, OpenCPMD or the reference evaluator | ~0~ skips the stress tensor on periodic cells; any other value, or unset, computes it |
| ~CPMDC_SCF_STEPS~ | ~src/cpmd_embed_c_api.F90~, each OpenCPMD evaluation | ~1~ writes ~cpmdc_warm_start~, ~cpmdc_wfn_extrapolated K~, and ~cpmdc_scf_steps N~ to the error stream |
| ~CPMDC_WARM_RMSD~ | ~src/cpmd_embed_c_api.F90~, each OpenCPMD evaluation | largest root-mean-square distance per atom, Angstrom, at which stored orbitals start the SCF; default 0.15, a negative value takes them at any distance |
| ~CPMDC_RECENTER~ | ~src/cpmd_embed_c_api.F90~, each OpenCPMD evaluation on an isolated deck | ~mass~ (default) or ~geometry~ moves the atoms rigidly so that that centre is the middle of the cell along every non-periodic lattice vector, and removes the net force; ~off~ keeps the caller's coordinates; any other value fails the call |
| ~CPMDC_RECENTER_MARGIN~ | same place | least distance, Angstrom, between an atom and a face of the isolated cell after the move; a closer atom fails the call; default 0, a negative value turns the check off, a value that does not parse fails the call |
| ~CPMDC_RANK_CONSENSUS~ | ~src/cpmdc.c~, each evaluation under a running MPI | ~1~ gives every rank of the calculator rank 0's energy, gradient, and result snapshots, and records the rank spread; any other value, or unset, leaves each rank's own result |

The first call of an OpenCPMD session fails when neither
~CPMDC_PSEUDO_DIR~ nor ~CPMD_PP_LIBRARY_PATH~ names an existing directory.
The result message and ~cpmdc_last_error()~ name that directory; the call
does not report an unconverged SCF.
While ~cpmdc~ is in the pseudopotential directory it also sets
~CPMD_PP_LIBRARY_PATH~ and ~PP_LIBRARY_PATH~ to that directory with a
trailing slash, for OpenCPMD's own lookup.
The change of directory is needed because OpenCPMD's ~get_pplib~ takes
~argv[2]~ as the library path whenever the process has more than one
argument, which most hosts do.
Once the pseudopotential files are read, the working directory becomes
~permanentDir~ if that field is set, otherwise ~scratchDir~, otherwise the
host directory from before the call.
A library force call writes no ~RESTART.1~, ~LATEST~, ~GEOMETRY~, or
~GEOMETRY.xyz~ there.
~cpmd.x~ writes those files in that directory.
The pseudopotential directory is left unchanged.

~CPMDC_STRESS=0~ saves the stress calculation for callers that use only energy
and forces, and the stress snapshot stays invalid.
Isolated cells never compute stress, whatever the variable says, and the
snapshot stays invalid for them even when the box volume is positive.

An isolated deck (~SYMMETRY 0~, a Poisson solver, ~CLUSTER~, ~SURFACE~ or
~POLYMER~) holds the density on a box of fixed size with its origin at a
corner, so a host whose atoms drift towards a face, or leave the box, puts
density across that face.
With ~CPMDC_RECENTER~ at ~mass~ or ~geometry~ the energy is that of the
atoms moved to the middle of the box, a function of their relative
positions only, and the forces are its gradient with respect to the
caller's coordinates: the net force the grid leaves is projected out, the
fraction of it each atom carries given by its weight in the centre.
Energy, forces and ~sum_i x_i (x) f_i~ then do not change when the caller
translates every atom.
On one BLYP water in the 10 Angstrom Hockney box with ~off~, a hydrogen
0.5 Angstrom from a face raises the energy by 5.0e-4 Hartree, a hydrogen
0.5 Angstrom past it lowers it by 8.4e-3 Hartree with a net force of
0.17 Hartree/Bohr, and the water about the corner lowers it by
7.9e-2 Hartree; with ~mass~ all of these give the energy of the centred
molecule to 1.1e-14 Hartree (~bench/results/cluster_drift_scan.org~).
A slab (~SURFACE~) moves only along its normal and a wire (~POLYMER~) only
across its axis.
Warm-start distances and stored orbitals use the moved coordinates; the
caller's arrays are not changed.
A periodic deck is not moved.
The margin applies with ~off~ too, so by default an atom outside the cell
fails the call instead of running with density across a face;
~CPMDC_RECENTER_MARGIN=-1~ lets it run, as releases before the recentring
did.
~cpmd.x~ keeps the deck's coordinates, so a comparison with it needs
~CPMDC_RECENTER=off~, and ~CPMDC_RECENTER_MARGIN=-1~ for atoms outside the
cell; the ~water-capnp-cli-parity~ and ~extrapolate-wfn~ tests set both.

~CPMDC_SCF_STEPS=1~ writes one line, ~cpmdc_scf_steps N~, for each SCF that
returns.
~N~ is that SCF's iteration count.
Before each evaluation it also writes ~cpmdc_warm_start S D~: where the SCF
starts (~S~ 0 the selected key's stored orbitals, 1 another key's parked
orbitals, -1 the deck's guess because every stored geometry lies beyond
~CPMDC_WARM_RMSD~) and the nearest distance ~D~ in Angstrom, or
~cpmdc_warm_start -2~ when nothing is stored.
Lines with a distance also include ~donor_key=K~, the key whose converged
orbitals supply the selected history, and ~periodic=T~ or ~periodic=F~,
the native boundary model used for the distance. A rejected history's donor
key describes the nearest stored candidate, not an accepted warm start.
A call whose orbitals start from the ~EXTRAPOLATE WFN~ prediction writes ~cpmdc_wfn_extrapolated K~ before its ~cpmdc_scf_steps~ line, with ~K~ the number of earlier converged orbital sets that the prediction combined.
Each line is flushed as it is written, so a log file shows it while the host runs.

~CPMDC_WARM_RMSD~ is the distance limit of [[file:../explanation/wavefunction-state.org][the stored orbitals]] (section Distance limit).
A value that does not parse as a number keeps the default.

~CPMDC_RANK_CONSENSUS=1~ adds three collectives to each evaluation on the
calculator communicator: the one bound or adopted, or ~MPI_COMM_WORLD~ when
neither call was made.
Every rank fails when one rank failed, and every rank resets its CPMD state
when one rank stopped.
A repeat of the stored positions returns the stored result only when every
rank repeats.
~cpmdc_last_rank_spread()~ then reports the largest energy and gradient
difference from rank 0 before the broadcast.
Set it to the same value on every rank.
A build without MPI ignores it.

* Read by the tests and tools

| Variable | Read by | Effect |
|----------+---------+--------|
| ~CPMD_ROOT~, then ~CPMDC_CPMD_ROOT~ | ~tools/check_feature_inventory.py~ (~feature-inventory~ test) | OpenCPMD source tree to probe for ~inscan('&SECTION')~ calls; without it the live completeness check is skipped with a warning |
| ~CPMD_SRC~, then ~OPENCPMD_SRC~ | ~tests/test_cpmd_inscan_token_fidelity.py~ | OpenCPMD source tree for the parser token check |
| ~CPMDC_CPMD_EXE~, then ~CPMD_ROOT~ | ~tools/cpmd_root_probe.py~ | the ~cpmd.x~ to check, or the tree whose ~bin/cpmd.x~ it checks |
| ~MAKE~, ~AR~ | ~tools/rebuild_opencpmd_embed.sh~ | the Make and archiver programs; default ~make~ and ~ar~ |

The live tests of an OpenCPMD build (~meson test -C build-cpmd~) run
~libcpmdc~, so they need ~CPMDC_PSEUDO_DIR~ like any other host.

* Read by hosts that load libcpmdc
These belong to the host, not to ~cpmdc~, and are listed here because they
decide which ~libcpmdc~ a host loads.

| Variable | Host | Effect |
|----------+------+--------|
| ~CPMDC_LIBRARY~, ~RGPOT_CPMDC_ENGINE~, ~RGPOT_CPMD_ENGINE~ | ~rgpot~ ~CPMDPot~ and ~python/cpmdc~ | path of the ~libcpmdc.so~ to ~dlopen~, tried in that order after an explicit engine path |
| ~CPMDC_SCHEMA~ | ~python/cpmdc~ ~find_schema~ | path of ~schema/Potentials.capnp~ for encoding ~CPMDParams~ text; a cell needs no schema, because the package encodes ~ForceInput~ itself |
| ~RGPOT_PARAMS_PATH~ | eOn ~RgpotPot~ builds that read ~params_path~ | overrides ~[RgpotPot] params_path~ |
| ~OMP_NUM_THREADS~ | OpenMP runtime | threads per rank inside CPMD when OpenCPMD was built with OpenMP |
