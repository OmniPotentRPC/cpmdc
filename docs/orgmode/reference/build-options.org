* Meson options
Every option of ~meson_options.txt~.
Pass one as ~-DNAME=VALUE~ to ~meson setup~.

| Option | Type | Default | Effect |
|--------+------+---------+--------|
| ~with_tests~ | boolean | ~true~ | build the cmocka suites, contract checks, and ~example_host_step~ |
| ~with_cpmd~ | boolean | ~false~ | link OpenCPMD instead of the reference evaluator; takes effect only with a non-empty ~cpmd_root~ |
| ~cpmd_root~ | string | empty | OpenCPMD build tree holding ~lib/libcpmd.a~, ~obj/~, and ~src/~ |
| ~with_mpi~ | feature | ~auto~ | link MPI into the default library; ~disabled~ keeps it serial. ~with_cpmd~ always needs MPI |
| ~with_python~ | boolean | ~false~ | install ~python/cpmdc~, its schema, and an unversioned ~libcpmdc~ for a wheel; ~pyproject.toml~ sets it, and it turns off the LAMMPS plugin, the GROMACS library, and the install of ~cpmdc-ipi-c~ |
| ~with_readcon~ | boolean | ~false~ | link ~readcon-core~ (Rust) for ~cpmdc-restart export-con~ and ~import-con~ |
| ~with_pwscale~ | boolean | ~false~ | build the plane-wave scaling scaffold ([[file:pwscale.org][reference]], [[file:../howto/pwscale-ranks.org][rank how-to]]); it is not on the force path |
| ~with_pwscale_cuda~ | boolean | ~false~ | compile the CUDA backend of that scaffold |
| ~with_lammps_plugin~ | feature | ~auto~ | build ~cpmdcplugin.so~, the LAMMPS ~pair_style cpmdc~; needs a C++ compiler, MPI for C++, and the LAMMPS headers (see [[file:../howto/lammps.org][the LAMMPS how-to]]) |
| ~lammps_include~ | string | empty | directory holding ~lammps.h~ and ~pair.h~; empty takes ~include/lammps~ of an importable ~lammps~ Python package |
| ~with_gromacs_shim~ | feature | ~auto~ | build ~libcpmdc_gromacs~ and ~libcp2k.pc~ for the GROMACS QM/MM interface (see [[file:../howto/gromacs.org][the GROMACS how-to]]) |

Configuration stops when ~with_cpmd=true~ and ~DIR/lib/libcpmd.a~ or
~DIR/obj/timetag.o~ is missing.
OpenCPMD keeps ~timetag~ outside the archive, and ~header~ calls it.

* Darwin link behavior for wheels
The serial wheel (~with_cpmd=false~) builds ~libcpmdc~ without a reference to
~cpmd_stopgm_hook~. On ELF, an undefined weak reference can remain unresolved,
but ~ld64~ reports that same reference as undefined at link time. The Darwin
stop hook is used only when ~with_cpmd=true~ and ~cpmd_root~ is non-empty.
~has_cpmd~ is the pair that passes ~-DCPMDC_HAS_CPMD=1~ and links ~libcpmd.a~.

On Darwin, the export list also differs by build mode: the serial library
exports the literal public C ABI symbols, while an OpenCPMD build adds wildcard
patterns for MPI Fortran sentinel COMMON blocks. ~ld64~ requires every literal
~-exported_symbols_list~ name to exist in the linked image, but wildcard entries
match only symbols that are present.

* Installed artifacts
~meson install~ writes these under the prefix.

| Artifact | Installed as | Built when |
|----------+--------------+------------|
| ~libcpmdc~ | ~lib/libcpmdc.so.MAJOR~ | always |
| public headers | ~include/cpmdc/cpmdc.h~, ~cpmdc_features.h~, ~cpmdc_export.h~, ~cpmdc_restart.h~ | always |
| ~libcpmdc_restart.a~ | ~lib/libcpmdc_restart.a~ | always |
| ~cpmdc-restart~ | ~bin/cpmdc-restart~ | always |
| pkg-config files | ~lib/pkgconfig/cpmdc.pc~, ~cpmdc-restart.pc~ | always |
| CMake package | ~cpmdcConfig.cmake~, imported target ~cpmdc::cpmdc~ | always |
| ~cpmdc-ipi-c~ | ~bin/cpmdc-ipi-c~ | the platform has ~sys/un.h~ and ~with_python~ is off |
| ~cpmdcplugin.so~ | ~lib/cpmdc/cpmdcplugin.so~ | ~with_lammps_plugin~ finds the LAMMPS headers |
| ~libcpmdc_gromacs~ | ~lib/libcpmdc_gromacs.so~, ~include/cpmdc/gromacs/libcp2k.h~, ~lib/cpmdc/gromacs/pkgconfig/libcp2k.pc~ | ~with_gromacs_shim~ is not disabled and ~with_python~ is off |

~MAJOR~ is the soversion, the first field of ~version.txt~.
The stub archive ~libcpmdc_stub.a~ is built for the tests and not installed.

* Pixi tasks

| Task | Environment | Runs |
|------+-------------+------|
| ~test-stub~ | default | configure ~build/~, compile, full Meson suite |
| ~test-cmocka~ | default | the ~cmocka~ suite only |
| ~test-e2e~ | default | the ~e2e~ suite only (single point and optimizer session) |
| ~test-readcon~ | default | the ~restart~ and ~restart-con~ suites in ~build-readcon/~ with ~-Dwith_readcon=true~ |
| ~test-stub-sanitize~ | default | full suite and the ~-Dwith_pwscale=true~ scaffold in ~build-sanitize/~ under AddressSanitizer and UndefinedBehaviorSanitizer |
| ~check-api-reference~ | default | ~tests/test_reference_contract.py~: every public C and Python name is in the reference pages |
| ~fortran-lint~ | default | ~fprettify --diff~ over ~src/*.f90~ |
| ~prek~, ~prek-install~, ~prek-validate~ | default | pre-commit hooks from ~prek.toml~ |
| ~lychee~ | ~docs~ | link check over README, ~docs/orgmode~, and news fragments |
| ~release-assert~, ~version-sync~, ~towncrier-draft~, ~release-cog-dry~ | default | release metadata checks, and ~version.txt~ copies |
| ~mkrst~ | ~docs~ | export ~docs/orgmode~ to ~docs/source~ RST |
| ~doxybuild~ | ~docs~ | Doxygen XML and Doxyrest pages for the public headers |
| ~sphinxbld~, ~docbld~ | ~docs~ | ~mkrst~, ~doxybuild~, then the Sphinx HTML site in ~docs/build~ |

Run a docs task with ~pixi run -e docs docbld~.

One sanitizer CI failure was traced to libfabric's memhooks monitor replacing
AddressSanitizer's ~mprotect~ interceptor during ~MPI_Init~.  In a separate
Open MPI 5 reproduction, ~FI_MR_CACHE_MONITOR=disabled~ alone still ended in
SIGILL, while ~--mca memory ^patcher~ prevented it.  Selecting a non-UCX
transport also prevented that reproduction.  The sanitize job disables the
observed libfabric path, and ~tests/run_mpi_test.py~ passes the Open MPI memory
and transport exclusions in both the environment and launcher arguments.
