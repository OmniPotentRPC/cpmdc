* Names
The public names live in ~python/cpmdc~.
Importing ~cpmdc~ does not import ASE.
Import ~cpmdc.ase~ for ~CPMDCCalculator~ and its ~CalculationFailed~.
~cpmdc.ipi~ is the ~cpmdc-ipi~ socket driver; it needs ASE only for
~--structure~.
~cpmdc.lammps~ couples a ~lammps~ object from LAMMPS' Python module; it imports
neither LAMMPS nor ~mpi4py~ until a run needs them.
~cpmdc.gromacs~ writes the grompp ~-qmi~ input of ~libcpmdc_gromacs~ and holds
GROMACS' unit factors; it imports nothing outside the standard library.

| Name | Role |
|------+------|
| ~HARTREE_TO_EV~ | Hartree to eV, the constant in ~src/cpmdc.c~ |
| ~BOHR_TO_ANGSTROM~ | Bohr to Angstrom, the CODATA 2018 constant in ~src/cpmdc_params.h~ |
| ~HARTREE_TO_KCAL_PER_MOL~ | Hartree to kcal/mol from CODATA 2018, the Avogadro constant, and 4.184 J per calorie |
| ~CPMDCError~ | failure from the library or from loading it |
| ~CpmdcError~ | deprecated name of ~CPMDCError~, the same class; reading it warns with ~DeprecationWarning~ |
| ~Evaluation~ | ~energy_h~, ~forces_h_bohr~, ~stress_h_bohr3~ (~None~ without a tensor), ~dipole_e_bohr~ (~None~ unless OpenCPMD recomputed it) |
| ~ConstantCutoff~ | frozen dataclass of the constant-cutoff kinetic functional, ~ConstantCutoff(cutoff_ry, height_ry=None, width_ry=None)~; a value that is not finite and positive raises ~ValueError~, and one that is not a number ~TypeError~ |
| ~ConstantCutoff.cutoff_ry~, ~ConstantCutoff.height_ry~, ~ConstantCutoff.width_ry~ | E0, A, and sigma in Ry; ~None~ selects 50 times the deck cutoff for A and E0 / 10 for sigma |
| ~ConstantCutoff.coerce~ | ~None~, a ~ConstantCutoff~, a mapping of its fields, or E0 in Ry, to a ~ConstantCutoff~ or ~None~ |
| ~ConstantCutoff.todict~ | the fields that are set, as JSON data |
| ~Session~ | one ~CPMDCSession~ handle; ~constant_cutoff=~ takes what ~ConstantCutoff.coerce~ takes and calls ~cpmdc_session_set_constant_cutoff()~; ~schema~ is deprecated and ignored |
| ~Session.energy_forces~ | one geometry, native units; a cell is encoded as ~ForceInput~ in process |
| ~Session.calculate_au~ | one step through ~cpmdc_session_calculate_au()~ from Bohr positions, atomic numbers, and an optional cell in Bohr with one vector per row; returns the energy in Hartree, ~3N~ forces in Hartree/Bohr, and the nine-component row-major virial ~-dE/d(strain)~ in Hartree; C-contiguous ~float64~ inputs pass without a copy, and writable ~forces=~ and ~virial=~ buffers are filled in place |
| ~Session.select_orbitals~ | call ~cpmdc_session_select_orbitals()~ for this session |
| ~Session.copy_orbitals~ | call ~cpmdc_session_copy_orbitals()~ to copy a stored orbital key into another key |
| ~Session.version~ | ~cpmdc/~ and the version string |
| ~Session.abi_version~ | numeric ABI generation |
| ~Session.available~ | true when OpenCPMD is linked, false for the reference evaluator |
| ~Session.close~ | destroy the handle; a later step raises ~CPMDCError~ |
| ~Potential~ | rgpot-shaped provider over one session; ~constant_cutoff=~ goes to ~Session~; ~schema~ is deprecated and ignored |
| ~Potential.evaluate~ | eV, eV/Angstrom, optional row-major stress in eV/Angstrom^3, and optional ~dipole~ in e*Angstrom |
| ~Potential.caps~ | ~stress~ and ~dipole~ true, ~energies~ false |
| ~Potential.close~ | close the owned session |
| ~find_library~ | explicit path, the three environment variables, the wheel's library, the dynamic linker, then ~build/~ |
| ~find_schema~ | explicit path, ~CPMDC_SCHEMA~, the wheel's copy, then ~schema/Potentials.capnp~; for ~capnp encode~ of ~CPMDParams~ text |
| ~forces_to_ev_per_angstrom~ | Hartree/Bohr forces to eV/Angstrom |
| ~dipole_to_e_angstrom~ | electron Bohr dipole to e*Angstrom |
| ~stress_to_ev_per_angstrom3~ | row-major Hartree/Bohr^3 tensor to eV/Angstrom^3, library sign |
| ~CPMDCCalculator~ | ASE calculator: energy, free_energy, forces, stress, and dipole when available; keywords ~params~, ~library~, and ~constant_cutoff~, and ASE's ~directory~, ~label~, ~atoms~, and ~parameters~ |
| ~CPMDCCalculator.default_parameters~ | ~params~, ~library~, and ~constant_cutoff~, all ~None~; a ~constant_cutoff~ is stored as E0 in Ry, or as the mapping of ~ConstantCutoff.todict~ when it sets a height or a width |
| ~CPMDCCalculator.implemented_properties~ | ~energy~, ~free_energy~, ~forces~, ~stress~, and ~dipole~ |
| ~CPMDCCalculator.ignored_changes~ | ~initial_charges~ and ~initial_magmoms~: a change of either keeps the stored results, because ~params~ sets the charge and the multiplicity |
| ~CPMDCCalculator.discard_results_on_any_change~ | ~True~: a parameter that ~set~ changes clears the stored results |
| ~CPMDCCalculator.calculate~ | one step with ~directory~ as the working directory; fills energy, free_energy, forces, and any available stress and dipole |
| ~CPMDCCalculator.set~ | change ~params~, ~library~, or ~constant_cutoff~, open a new session, clear results, return a dictionary of the changed parameters; ~parameters~ reads a saved file, and any other key raises ~TypeError~ |
| ~CPMDCCalculator.todict~ | the parameters as JSON data; a ~params~ buffer of bytes is left out |
| ~CPMDCCalculator.reset~ | clear the stored results; the session stays open |
| ~CPMDCCalculator.potential~ | the ~Potential~ the calculator owns, opened on first use |
| ~CPMDCCalculator.close~ | close that potential; the next step opens a new one |
| ~cpmdc.ase.CalculationFailed~ | a step that the library rejected; both ASE's ~CalculationFailed~ and ~CPMDCError~, with the step's working directory in the message |
| ~cpmdc.ipi.Driver~ | answer i-PI protocol requests from one ~Session~; ~params~, the fixed ~atomic_numbers~, then the ~library~, ~cluster~, and ~log~ keywords |
| ~Driver.compute~ | one step from ~3N~ Bohr positions and the wire's cell ~h~ (lattice vectors as columns, Bohr), in that order; returns Hartree, Hartree/Bohr, and the virial ~-dE/d(strain)~ in Hartree |
| ~Driver.serve~ | answer a connected socket until ~EXIT~ or a closed connection; return the step count |
| ~Driver.close~ | close the session |
| ~cpmdc.ipi.ProtocolError~ | a ~CPMDCError~ for a message the driver cannot answer |
| ~cpmdc.ipi.connect~ | open the UNIX or TCP socket to the server, retrying for ~wait~ seconds |
| ~cpmdc.ipi.species_numbers~ | atomic numbers from ~"O H H"~, ~"O,H,H"~, ~"OH2"~, or ~"8 1 1"~ |
| ~cpmdc.ipi.unix_socket_path~ | the socket file for an address, with the i-PI and ASE prefix |
| ~cpmdc.ipi.main~ | the ~cpmdc-ipi~ command; returns the exit status |
| ~cpmdc.lammps.FixExternal~ | cpmdc as the force engine of a ~fix external pf/callback~; ~fix_id~, ~create~, ~library~, ~comm~ keywords |
| ~FixExternal.run~ | ~run~ with LAMMPS keywords; raises ~CPMDCError~ for a failed step |
| ~FixExternal.close~ | close the session and remove the fixes it added; also on leaving a ~with~ block |
| ~FixExternal.error~, ~energy~, ~evaluations~ | the last failure, the last energy in LAMMPS units, the evaluation count on rank 0 |
| ~FixExternal.periodic~, ~type_numbers~, ~units~ | whether the cell is sent, the atomic number of each atom type, the LAMMPS unit style |
| ~cpmdc.lammps.UNIT_STYLES~ | LAMMPS unit style to (length per Bohr, energy per Hartree) for ~metal~, ~real~, ~electron~ |
| ~cpmdc.lammps.unit_factors~ | that pair for one style; ~ValueError~ for any other |
| ~cpmdc.lammps.box_rows~ | ~boxlo~, ~boxhi~, ~xy~, ~yz~, ~xz~ to the 3x3 cell with one lattice vector per row |
| ~cpmdc.gromacs.qmi_input~ | text of the grompp ~-qmi~ file: ~params~, then ~cell~, ~embedding~, ~qm_charges~, ~ewald_rcut~ (nm), ~ewald_precision~, ~qm_ranks~ (~"ALL"~ or 1), ~charge~, ~multiplicity~ keywords; ~ValueError~ for a value the library would refuse |
| ~cpmdc.gromacs.write_qmi~ | write that text to a path and return it |
| ~cpmdc.gromacs.BOHR_TO_NM~, ~HARTREE_TO_KJ_PER_MOL~, ~HARTREE_PER_BOHR_TO_KJ_PER_MOL_NM~ | GROMACS' QM/MM conversion factors, built as ~src/gromacs/math/units.h~ builds them |
| ~cpmdc.lammps.type_numbers~ | ~type_numbers(elements, n_types)~: atomic numbers per atom type from ~"O H"~, ~"8 1"~, or a sequence; ~ValueError~ unless there are ~n_types~ |

~BOHR_TO_ANGSTROM = 0.529177210903~ is the [[https://physics.nist.gov/cgi-bin/cuu/Value?bohrrada0][2018 CODATA Bohr radius]]
in Angstrom. Dipole conversion multiplies electron Bohr by this value.

~free_energy~ on ~CPMDCCalculator~ equals ~energy~.
A repeated geometry returns the stored step.
A null or empty input raises; it does not abort the interpreter.
[[file:../howto/ase.org][Use cpmdc as an ASE calculator]] has the property table
and the rules for units, boundaries, caching, the working directory, copies, and
sessions.
[[file:../howto/socket-drivers.org][Drive cpmdc over the i-PI socket protocol]]
covers ~cpmdc-ipi~, and [[file:../howto/lammps.org][Run LAMMPS on cpmdc forces]]
covers ~cpmdc.lammps~.

* Errors

| Condition | Raised |
|-----------+--------|
| empty or invalid ~CPMDParams~, library not found, library call failed, closed ~Session~ | ~CPMDCError~ |
| a ~constant_cutoff~ whose E0 + 2 sigma exceeds the deck cutoff, on a message with a raw ~&SYSTEM~ block or with ~system.constantCutoff~, or on a library without ~cpmdc_session_set_constant_cutoff~ | ~CPMDCError~ |
| a ~CPMDCCalculator~ step that the library rejects | ~cpmdc.ase.CalculationFailed~, which is a ~CPMDCError~ and ASE's ~CalculationFailed~ |
| missing ~params~ file | ~FileNotFoundError~ |
| empty positions, a non-finite coordinate, an atomic number outside 1..118 | ~ValueError~ |
| ~atoms.pbc~ mixes periodic and open axes, or is periodic without three independent cell vectors | ~ValueError~ |
| a ~CPMDCCalculator~ step without atoms | ~ValueError~ |
| stress on free boundaries or an isolated deck; dipole when the evaluation did not recompute one; a property outside ~implemented_properties~ | ~ase.calculators.calculator.PropertyNotImplementedError~ |
| a keyword to ~CPMDCCalculator~ or ~CPMDCCalculator.set~ other than ~params~, ~library~, ~constant_cutoff~, and ASE's own, such as ~charge~ or ~multiplicity~; no ~params~, or ~params=None~ | ~TypeError~ |
| ~schema=~ on any class, ~restart=~ on ~CPMDCCalculator~ | ~DeprecationWarning~ |
| a changed atom count, a batched ~INIT~, a message out of order, a connection closed mid-message, or a flat cell on the socket | ~cpmdc.ipi.ProtocolError~ |
| ~Session.calculate_au~ with a failed evaluation; positions, numbers, cell, or output arrays of the wrong size | ~CPMDCError~; ~ValueError~ for the sizes |
| ~FixExternal~ on a unit style other than ~metal~, ~real~, ~electron~, on a box with mixed periodicity, or with the wrong number of elements | ~ValueError~ |
| ~FixExternal~ with unreadable ~params~, on several ranks without ~mpi4py~, or a failed step in ~FixExternal.run~ | ~CPMDCError~ |
