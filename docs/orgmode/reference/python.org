* Names
The public names live in ~python/cpmdc~.
~Session.energy_forces~ and ~Potential.evaluate~ take positions and cells in Angstrom (~Session.calculate_au~ takes Bohr).
~Session~ returns Hartree, Hartree/Bohr, and Hartree/Bohr^3 (with the virial in Hartree from ~calculate_au~), the native units of the C ABI.
~Potential~ returns eV, eV/Angstrom, and eV/Angstrom^3 with the ASE stress sign ~(1/V) dE/d(strain)~.
The [[file:contracts.org][API contracts]] page gives each name its signature, units, shape and dtype, ownership, thread behaviour, exceptions and defaults, and the ~reference-audit~ test keeps it in step with the code.
Importing ~cpmdc~ does not import ASE.
Import ~cpmdc.ase~ for ~CPMDCCalculator~ and its ~CalculationFailed~.
~cpmdc.ipi~ is the ~cpmdc-ipi~ socket driver; it needs ASE only for
~--structure~.
~cpmdc.lammps~ couples a ~lammps~ object from LAMMPS' Python module; it imports
neither LAMMPS nor ~mpi4py~ until a run needs them.
~cpmdc.gromacs~ writes the grompp ~-qmi~ input of ~libcpmdc_gromacs~ and holds
GROMACS' unit factors; it imports nothing outside the standard library.

| ~Session.energy_forces~ | ~energy_forces(positions, atomic_numbers, cell=None)~: evaluate one geometry from Angstrom ~positions~ of shape (N, 3), N integer ~atomic_numbers~ in 1..118, and optional Angstrom ~cell=None~ (3x3 or nine row-major floats, encoded as ~ForceInput~ in process, or ~None~ for an isolated system); returns ~Evaluation~ in Hartree, Hartree/Bohr, and Hartree/Bohr^3; raises ~CPMDCError~, ~TypeError~, or ~ValueError~ |
| ~Session.calculate_au~ | ~calculate_au(positions_bohr, atomic_numbers, cell_bohr=None, *, forces=None, virial=None)~: one step through ~cpmdc_session_calculate_au()~ from ~3 * N~ Bohr coordinates in ~positions_bohr~ (flat or N rows), N integer ~atomic_numbers~ in 1..118, and optional ~cell_bohr=None~ (nine Bohr values or three rows with one vector per row, or ~None~); returns ~(energy_h, forces, virial)~ with ~energy_h~ in Hartree, ~3 * N~ forces in Hartree/Bohr, and the nine-component row-major virial ~-dE/d(strain)~ in Hartree (zero without a cell or stress tensor); C-contiguous ~float64~ and ~int32~ inputs pass without a copy, and writable ~forces=None~ and ~virial=None~ ~float64~ buffers are filled in place when given (otherwise new ~array('d')~ buffers are returned); raises ~CPMDCError~, ~TypeError~, or ~ValueError~ |
| ~Session.select_orbitals~ | ~select_orbitals(key)~: call ~cpmdc_session_select_orbitals()~ with signed 64-bit integer ~key~ (dimensionless); raises ~TypeError~, ~ValueError~, or ~CPMDCError~ |
| ~Session.copy_orbitals~ | ~copy_orbitals(from_key, to_key)~: call ~cpmdc_session_copy_orbitals()~ to copy stored orbitals from signed 64-bit integer ~from_key~ into ~to_key~ (dimensionless); raises ~TypeError~, ~ValueError~, or ~CPMDCError~ |

| ~Potential~ | ~Potential(params, *, library=None, schema=None, constant_cutoff=None)~: rgpot-shaped provider and context manager over one ~Session~; ~params~ is serialized ~CPMDParams~ ~bytes~ or a file path (required); ~library=None~ and ~constant_cutoff=None~ (in Rydberg) go to ~Session~; ~schema=None~ is deprecated and ignored (~DeprecationWarning~ when not ~None~); raises ~CPMDCError~, ~FileNotFoundError~, ~TypeError~, or ~ValueError~ |

| ~find_schema~ | ~find_schema(path=None)~: return the ~Path~ of ~schema/Potentials.capnp~ for ~capnp encode~ of ~CPMDParams~ text; tries an explicit ~path~ first, then ~CPMDC_SCHEMA~, then the wheel's ~cpmdc/schema/Potentials.capnp~, then ~schema/Potentials.capnp~ in the working directory; raises ~CPMDCError~ when not found |

| ~CPMDCCalculator~ | ASE calculator: ~CPMDCCalculator(params=None, *, library=None, constant_cutoff=None, **kwargs)~ for ~energy~ (eV), ~free_energy~ (eV), ~forces~ (eV/Angstrom), and ~stress~ (eV/Angstrom^3, Voigt); takes ~params~, ~library~, and ~constant_cutoff~ (Rydberg), and ASE's ~directory~, ~label~, ~atoms~, and ~parameters~ |

~free_energy~ on ~CPMDCCalculator~ equals ~energy~.
A repeated geometry returns the stored step.
A null or empty input raises; it does not abort the interpreter.

* Errors

| Condition | Raised |
|-----------+--------|
| empty or invalid ~CPMDParams~, library or schema not found, library load or call failed, closed ~Session~, changed atom count or composition | ~CPMDCError~ |
| a ~constant_cutoff~ whose E0 + 2 sigma exceeds the deck cutoff, on a message with a raw ~&SYSTEM~ block or with ~system.constantCutoff~, or on a library without ~cpmdc_session_set_constant_cutoff~ | ~CPMDCError~ |
| ~Session.copy_orbitals~ on a library without ~cpmdc_session_copy_orbitals~, before any evaluation, or from a key without converged orbitals | ~CPMDCError~ |
| a ~CPMDCCalculator~ step that the library rejects | ~cpmdc.ase.CalculationFailed~, which is a ~CPMDCError~ and ASE's ~CalculationFailed~ |
| missing ~params~ file | ~FileNotFoundError~ |
| empty or non-3D positions, mismatched ~atomic_numbers~ or ~numbers~ length, a cell or box that is not 3x3 or 9 numbers, a ~stress_h_bohr3~ without 9 components, a non-finite coordinate or cell value, an atomic number outside 1..118, a non-positive or non-finite ~ConstantCutoff~ field, a whole-number argument that is a fraction such as ~14.9~, an orbital key outside the signed 64-bit range | ~ValueError~ |
| an atomic number, orbital key, ~ConstantCutoff~ field, or ~charge~ that is a string, ~None~, or ~bool~; a coordinate or cell value that is not a real number | ~TypeError~ |
| ~atoms.pbc~ mixes periodic and open axes, or is periodic and the cell has rank below 3 under the numpy.linalg.matrix_rank cutoff | ~ValueError~ |
| a ~CPMDCCalculator~ step without atoms | ~ValueError~ |
| stress on free boundaries or an isolated deck; a property outside ~implemented_properties~ | ~ase.calculators.calculator.PropertyNotImplementedError~ |
| a keyword to ~CPMDCCalculator~ or ~CPMDCCalculator.set~ other than ~params~, ~library~, ~constant_cutoff~, and ASE's own, such as ~charge~ or ~multiplicity~; no ~params~, or ~params=None~ | ~TypeError~ |
| ~schema=~ on any class, ~restart=~ on ~CPMDCCalculator~ | ~DeprecationWarning~ |
| a changed atom count, an ~INIT~ whose ~batch_size~ is not the integer 1, a message out of order, a connection closed mid-message, or a cell of rank below 3 on the socket | ~cpmdc.ipi.ProtocolError~ |
| ~Session.calculate_au~ with a failed evaluation; positions, numbers, cell, or output arrays of the wrong size, or non-writable or non-contiguous ~forces~ or ~virial~ buffers | ~CPMDCError~; ~ValueError~ for the sizes, buffers, non-finite values, and atomic numbers outside 1..118; ~TypeError~ for non-numeric coordinates or non-integer atomic numbers |
| ~FixExternal~ on a unit style other than ~metal~, ~real~, ~electron~, on a box with mixed periodicity, or with the wrong number of elements | ~ValueError~ |
| ~FixExternal~ with unreadable ~params~, on several ranks without ~mpi4py~, or a failed step in ~FixExternal.run~ | ~CPMDCError~ |
