#+TITLE: Public C surface map
#+OPTIONS: toc:nil todo:nil num:nil author:nil title:t

A cross-check of the in-process C ABI: every public function against the
header, the inventory, both implementations, and the feature table.
The [[file:c-abi.org][C ABI reference]] documents what each function does; this page
records where each one lives.
The ~cpmd-public-abi-inventory~, ~stub-abi-symbol-coverage~,
~shared-dlopen-symbol-coverage~, and ~c-abi-inventory~ tests keep it true.

* Exported symbols
~schema/inventory/surface_map_abi.txt~ is generated by
~scripts/abi_inventory.py~ from the exported symbols of ~libcpmdc~
(~nm -D --defined-only~, or ~nm -gU~ on macOS; ~NM~ names another ~nm~) and
the declarations in ~include/cpmdc.h~ and ~include/cpmdc_features.h~.
It lists the 45 public functions with their header and the ABI generation a
declaration records with ~@since~.
~libcpmdc~ exports exactly those symbols: internal glue is hidden (see
[[file:c-abi.org][the C ABI reference]] for ~CPMDC_API~ and the export list).

The ~c-abi-inventory~ test, in the ~abi~ and ~inventory~ suites, and the CI
stub job fail when the file differs from what the built library and the
headers give, when a public declaration lacks ~CPMDC_API~ or is not
exported, or when the library exports any other symbol, internal ~cpmdc_~
glue and symbols of the linked static archives alike.
The ~shared-dlopen-abi~ test also checks that internal C and Fortran glue
does not resolve through ~dlsym~.
After changing the surface, regenerate the file with
~meson compile -C build abi-inventory~.

~scripts/abi_baseline.txt~ and the ~c-abi-baseline~ test are separate: they
freeze the exported names so a removal or a rename fails.

* Parser sections
The 25 sections OpenCPMD reads with ~inscan('&SECTION')~, recorded in
~opencpmd_inscan_sections~ and ~schema/inventory/opencpmd_sections.txt~:

ATOM, ATOMS, BASIS, CLAS, CPMD, DFT, EAM, EXTE, HARDNESS, INFO, LINRES,
MOLSTATES, MTS, NLCC, PATH, PIMD, POTENTIAL, PROP, PTDDFT, RESP, SYSTEM,
TDDFT, VDW, VECTORS, WAVEFUNCTION.

QMMM, PROPERTIES, BICANONICAL, and CDFT are ~&CPMD~ keywords, not sections.
