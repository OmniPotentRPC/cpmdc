#+OPTIONS: toc:nil todo:nil num:nil author:nil title:t

A cross-check of the in-process C ABI: every public function against the
header, the inventory, both implementations, and the feature table.
The [[file:c-abi.org][C ABI reference]] documents what each function does; this page
records where each one lives.
The ~cpmd-public-abi-inventory~, ~stub-abi-symbol-coverage~, and
~shared-dlopen-symbol-coverage~ tests keep it true.

* Parser sections
The 25 sections OpenCPMD reads with ~inscan('&SECTION')~, recorded in
~opencpmd_inscan_sections~ and ~schema/inventory/opencpmd_sections.txt~:

ATOM, ATOMS, BASIS, CLAS, CPMD, DFT, EAM, EXTE, HARDNESS, INFO, LINRES,
MOLSTATES, MTS, NLCC, PATH, PIMD, POTENTIAL, PROP, PTDDFT, RESP, SYSTEM,
TDDFT, VDW, VECTORS, WAVEFUNCTION.

QMMM, PROPERTIES, BICANONICAL, and CDFT are ~&CPMD~ keywords, not sections.
