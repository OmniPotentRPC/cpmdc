#+TITLE: An energy and forces from ASE
#+OPTIONS: toc:nil todo:nil num:nil author:nil title:t

* Run the example
This lesson evaluates the same internal water geometry as the [[file:first-energy.org][first tutorial]],
placed near the origin rather than at ~(5, 5, 5)~, with the ASE calculator.
The default build's origin-anchored reference well supplies the number.
No OpenCPMD checkout is required.

Build and test the default tree with ~pixi run test-stub~ (or
~meson setup build -Dwith_tests=true~ followed by ~meson test -C build~ or ~meson compile -C build cpmdc water_params_bin~),
as the [[file:../howto/quickstart.org][build-and-test how-to]] does.
Plain ~meson compile -C build~ compiles
~build/libcpmdc.so~ while the test run or ~water_params_bin~ target writes the encoded water message ~build/water_blyp_params.bin~.
Point the example at both from the root of the checkout:

#+begin_src bash
export CPMDC_PARAMS=build/water_blyp_params.bin
export CPMDC_LIBRARY=build/libcpmdc.so
export PYTHONPATH=python
python3 examples/python/ase_energy.py
#+end_src

#+begin_src text
energy_ev=0.059020309570
natoms=3
fmax=0.06513409
#+end_src

~energy_ev~ is the reference energy in eV.
~fmax~ here is the largest absolute force component in eV/Angstrom; ASE
optimizers compare their ~fmax~ with the largest force norm instead.
The same geometry without ASE is ~examples/python/energy.py~, which prints
Hartree.

With ~pip install "cpmdc[ase]"~ the package and its library come from the wheel,
so drop ~CPMDC_LIBRARY~ and ~PYTHONPATH~ and keep ~CPMDC_PARAMS~.

~CPMDCCalculator~ keeps one session.
A second ~get_potential_energy~ on the same atoms does not recompute, and
neither does ~get_forces~ after it: one step computes both.
~get_forces~ returns an array of shape ~(natoms, 3)~.
Change a position and the next call computes again on the same session, which a
relaxation with ~BFGS~ and ~FixAtoms~ relies on.
~energy~ is in eV and ~forces~ in eV/Angstrom, matching ASE's unit system and
converted from Hartree and Bohr with ~cpmdc.HARTREE_TO_EV~ and
~cpmdc.BOHR_TO_ANGSTROM~ (CODATA 2018).
~tests/python/test_ase_conformance.py~ checks those units, the cache, and the
errors of the calculator with ASE's own tools, against the same reference well.
[[file:../howto/ase.org][Use cpmdc as an ASE calculator]] lists every property,
the units, the boundary rules, and the working directory, and shows how to relax
a structure and its cell with an ASE optimizer.
