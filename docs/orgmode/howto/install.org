* What gets built
A ~cpmdc~ build produces one shared library, ~libcpmdc.so~, and a few helpers
around it.
The build has two modes, selected by the Meson option ~with_cpmd~:

| Mode | Option | Evaluator behind the C ABI | ~cpmdc_available()~ |
|------+--------+----------------------------+---------------------|
| Default | ~-Dwith_cpmd=false~ | deterministic reference evaluator, no OpenCPMD | 0 |
| OpenCPMD | ~-Dwith_cpmd=true -Dcpmd_root=DIR~ | OpenCPMD linked from ~DIR/lib/libcpmd.a~ | 1 |

Both modes export the same symbols.
A third target,
~libcpmdc_stub.a~, is a link-only placeholder: every call fails and ~cpmdc_available()~
returns 0.
The tests use it to check the ABI without a working evaluator.

| Artifact | Installed as | Purpose |
|----------+--------------+---------|
| ~libcpmdc.so~ | ~lib/libcpmdc.so.MAJOR~ | the C ABI from ~include/cpmdc.h~ |
| public headers | ~include/cpmdc/cpmdc.h~, ~cpmdc_features.h~, ~cpmdc_export.h~, ~cpmdc_restart.h~ | declarations for hosts |
| ~libcpmdc_restart.a~ | ~lib/libcpmdc_restart.a~ | reader and writer for CPMD ~RESTART~ files |
| ~cpmdc-restart~ | ~bin/cpmdc-restart~ | command-line front end to ~libcpmdc_restart~ |
| pkg-config files | ~cpmdc.pc~, ~cpmdc-restart.pc~ | compiler and linker flags |
| CMake package | ~cpmdcConfig.cmake~ | imported target ~cpmdc::cpmdc~ |

The optional tools (~cpmdc-ipi-c~, the LAMMPS plugin, and ~libcpmdc_gromacs~)
are listed with the options that build them in the
[[file:../reference/build-options.org][build reference]].

~MAJOR~ is the soversion, the first field of ~version.txt~.

* Requirements
The checked-in Pixi manifest pins every build dependency.
Without Pixi, install the same set from your package manager:

| Dependency | Version in ~pixi.toml~ | Needed for |
|------------+------------------------+------------|
| Meson, Ninja | Meson 1.5.2 or newer, Ninja 1.11 or newer | every build |
| Cap'n Proto (~capnp~ compiler) | 1.0.2 or newer, below 2 | generating the schema readers, encoding messages |
| C and Fortran compilers | any recent GCC and gfortran | every build |
| C++ compiler and Rust (~cargo~) | Rust 1.70 or newer, below 2 | the ~minimage~ subproject |
| pkg-config | 2.5.1 or newer | dependency lookup |
| Python 3 | 3.10 or newer | build helpers and tests |
| ASE, pytest, i-PI | ASE 3.23 or newer, pytest 7 or newer, i-PI 3.3 or newer | the ~python-api~ and ~python-pytest~ tests |
| cmocka | 1.1.7 or newer | ~-Dwith_tests=true~ |
| MPI with Fortran bindings, BLAS and LAPACK | OpenMPI 4.1 to 5, OpenBLAS 0.3 | ~-Dwith_cpmd=true~ |
| FFTW3 | optional | linked when OpenCPMD was configured with FFTW3 |

The C Cap'n Proto runtime (~c-capnproto~) is vendored in ~subprojects/~.
Meson fetches three subprojects on the first ~meson setup~: the shared schema
(~potentials-schema~, pinned in ~subprojects/potentials-schema.wrap~),
~capnp-fortran~, and ~minimage~; ~-Dwith_readcon=true~ adds ~readcon-core~.
On a machine without network access, download them first where the network is
available:

#+begin_src bash
meson subprojects download
#+end_src

* Build the default library
Clone the repository and run the default suite:

#+begin_src bash
git clone https://github.com/OmniPotentRPC/cpmdc.git
cd cpmdc
pixi run test-stub
#+end_src

~test-stub~ configures ~build/~ with tests on, compiles, and runs the Meson
suite.
A healthy run reports no failures.
The same steps without Pixi:

#+begin_src bash
meson setup build -Dwith_tests=true
meson compile -C build
meson test -C build --print-errorlogs
#+end_src

The [[file:../reference/build-options.org][build reference]] lists every Meson
option, installed artifact, and Pixi task.

* Build against OpenCPMD
The OpenCPMD archive needs the patches in ~tools/~ and position-independent
code; the [[file:opencpmd-archive.org][archive how-to]] covers that build.
With the archive in place:

#+begin_src bash
export CPMD_ROOT=/path/to/opencpmd-build
meson setup build-cpmd \
  -Dwith_cpmd=true \
  -Dcpmd_root="$CPMD_ROOT" \
  -Dwith_tests=true
meson compile -C build-cpmd
export CPMDC_PSEUDO_DIR=/path/to/PP_LIBRARY
meson test -C build-cpmd --print-errorlogs
#+end_src

Configuration stops when
~$CPMD_ROOT/lib/libcpmd.a~ or ~$CPMD_ROOT/obj/timetag.o~ is missing.
The live tests run OpenCPMD, which reads the pseudopotentials from
~CPMDC_PSEUDO_DIR~ (see the
[[file:../reference/environment.org][environment reference]]).

The link uses the MPI Fortran dependency, OpenBLAS (or LAPACK and BLAS when
OpenBLAS is absent), FFTW3 when found, ~libgfortran~, and ~libquadmath~.
When OpenCPMD was built with MPI compiler wrappers, configure with the same
wrappers so both sides agree on one MPI:

#+begin_src bash
CC=mpicc FC=mpif90 meson setup build-cpmd \
  -Dwith_cpmd=true -Dcpmd_root="$CPMD_ROOT"
#+end_src

* Install
#+begin_src bash
meson setup build-install --prefix "$HOME/.local" -Dwith_tests=false
meson install -C build-install
pkg-config --modversion cpmdc
#+end_src

The last command prints the project version, which Meson reads from
~version.txt~.
Hosts that load the library at run time, such as ~rgpot~, look for it through
~CPMDC_LIBRARY~; see the
[[file:../reference/environment.org][environment reference]].

* Install the Python package
Release tags publish wheels for Linux x86_64 and aarch64 (manylinux_2_28) and
macOS arm64 (macOS 15 or newer).
One wheel per platform serves CPython 3.10 and newer; CI tests 3.10 to 3.13.
The ~ase~ extra installs ASE for ~cpmdc.ase~:

#+begin_src bash
pip install "cpmdc[ase]"
python -c "import cpmdc; print(cpmdc.find_library())"
#+end_src

The second command prints the ~libcpmdc~ inside the installed package.
That library is the default build: the reference evaluator, without OpenCPMD and
without MPI, so ~Session.available()~ is false.
The wheel carries ~libgfortran~ and ~schema/Potentials.capnp~.
A periodic cell needs no other tool: the package encodes each step as
~ForceInput~ itself.
The ~capnp~ command is needed only to encode a ~CPMDParams~ text file, and
~cpmdc.find_schema()~ returns the schema to encode it against.
The ~test~ extra adds pytest for ~tests/python~.
To evaluate with OpenCPMD, build ~libcpmdc~ with
~-Dwith_cpmd=true~ and set ~CPMDC_LIBRARY~ to it; the variable takes precedence
over the copy in the wheel.

On other platforms pip builds the sdist.
That needs the C, C++, and Fortran compilers, Rust (~cargo~, for the ~minimage~
subproject), the ~capnp~ command, and network access for the Meson subprojects.
The same build from a checkout:

#+begin_src bash
pip install ".[ase]"
#+end_src
