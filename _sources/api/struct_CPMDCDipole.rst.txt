Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Molecular dipole after a successful evaluation.

``valid`` is set only when OpenCPMD recomputed the dipole from the converged wavefunction for the current geometry. Values are electron Bohr.
