Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

How far the ranks of one calculator were from its rank 0.

Written by an evaluation that ran with ``CPMDC_RANK_CONSENSUS=1`` under a running MPI. The differences are taken before every rank receives rank 0's energy and gradient. A NaN difference is reported as infinity. Both are 0 when every rank held the same values.
