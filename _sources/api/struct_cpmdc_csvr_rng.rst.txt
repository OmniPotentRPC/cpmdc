Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Caller-owned generator for one CSVR trajectory.

The four state words are a xoshiro256\*\* generator. spare_normal and spare_ready hold one unused normal from the Box-Muller pair. Seed the object before a scale call. An all-zero object is rejected. The host owns the memory and may copy the bytes to replay a trajectory.
