Meson takes the project version from version.txt. pyproject.toml leaves the Python package version dynamic and takes it from that Meson version.

Configuration stops when with_cpmd=true, cpmd_root=DIR is non-empty, and DIR/lib/libcpmd.a or DIR/obj/timetag.o is missing. OpenCPMD keeps timetag outside the archive, and header calls it.

Darwin link behavior for wheels¶

The serial wheel (with_cpmd=false) builds libcpmdc without a reference to cpmd_stopgm_hook. On ELF, an undefined weak reference can remain unresolved, but ld64 reports that same reference as undefined at link time. The Darwin stop hook is used only when with_cpmd=true and cpmd_root is non-empty. has_cpmd is the pair that passes -DCPMDC_HAS_CPMD=1 and links libcpmd.a.

On Darwin, the export list also differs by build mode: the serial library exports the literal public C ABI symbols, while an OpenCPMD build adds wildcard patterns for MPI Fortran sentinel COMMON blocks. ld64 requires every literal -exported_symbols_list name to exist in the linked image, but wildcard entries match only symbols that are present.

Meson test suites¶

meson test -C build --suite NAME runs one suite. These suites group the tests of the default build by layer. meson test -C build --list lists every test.

Suite

Tests

stub

stub-abi, capabilities-cmocka, stub-abi-symbol-coverage, and when MPI is found adopt-comm-stub and bind-calculator-stub on four ranks

abi

exported header, symbol-table, baseline, and feature-discovery checks

cmocka, capnp, capnp-fortran

structured CPMDParams deck rendering, Fortran bridge application, and cmocka unit checks

params, inventory, schema

schema sync, field coverage, token fidelity, and CPMD catalog feature IDs

cpmdc

every registered test: Meson adds the project name as a suite to each test, so --suite cpmdc runs the whole default build, and geometry-rmsd, warm-selector, and warm-selector-abi belong to no other suite

socket

ForceInput sizing and session PotentialResult buffer contract

embed, dlopen, mpi

Fortran embed shell, dlopen ABI loading (dlopen-leak only when b_sanitize includes address), and the MPI tests. adopt-comm-shell and bind-calculator-shell run on four ranks; orbital-limit-agree-mpi, periodic-cell-mpi, and orbital-divergence-mpi run on two (those five join the opencpmd suite when has_cpmd is true). rank-consensus runs on four ranks and registers only when MPI is found and has_cpmd is false, because it compares exact per-rank values from the reference evaluator. The mpi suite also holds the two stub tests above. All MPI tests register only when MPI is found, and skip when no mpirun or mpiexec is on PATH

e2e, fd-check

one-shot and session calls, Python E2E, orbital extrapolation, and finite-difference force checks

python

Python bindings, pytest suite, mypy strict check (skips without mypy), and Python reference audit

restart

libcpmdc_restart binary RESTART reader/writer and header macro checks

packaging

installed RUNPATH, relocatable pkg-config layouts, and CMake/pkg-config consumer build

docs, examples

example-host-step, runnable documentation blocks, llms.txt freshness, and API reference contracts

The mpi tests above are added when with_tests=true and the C MPI dependency is found (rank-consensus also requires has_cpmd to be false). They launch through tests/run_mpi_test.py, which uses mpirun or mpiexec when one is on PATH, and otherwise exits 77 so Meson marks the test skipped.

Opt-in options add restart-con (-Dwith_readcon=true), pwscale (-Dwith_pwscale=true), and opencpmd plus water (-Dwith_cpmd=true with a non-empty cpmd_root).

In the e2e suite, e2e-single-point runs cpmdc_calculate_result and a session force call on one ForceInput, then cpmdc_energy_forces on bare positions. e2e-optimizer-session runs three geometry steps on one CPMDCSession, the topology rejection, and a second session for a change of species. Both skip when cpmdc_available() is 0, which is every build without OpenCPMD.

cmocka is resolved through pkg-config or CMake. The parser tests use Cap’n Proto text fixtures encoded by the capnp CLI (tests/encode_capnp.py). The stub archive only provides linkable symbols. The default shared libcpmdc evaluates sessions on the reference evaluator. Both return cpmdc_available() == 0, because that call means OpenCPMD is linked.

Meson test parallelism and BLAS threads¶

The default test setup (blasthreads) sets OPENBLAS_NUM_THREADS, OMP_NUM_THREADS, and MKL_NUM_THREADS to 1 so parallel meson test workers do not each spawn a full OpenBLAS pool. Meson applies those values to every test child; exports of the same names in the shell that runs meson test are not passed through. To force different caps, set them on the env: keyword of the individual test or run the executable outside Meson.
