API contracts¶

Every public name of cpmdc has one entry on this page: the exported C functions, the C types and constants, the Python names that each module lists in __all__ with the public members of its classes, and the properties and parameters of the ASE calculator. Each entry states the units, the array layout or shape, who owns every pointer or object, what threads and MPI ranks may do, every return or error code with the Python exception it becomes, and the defaults.

The reference-audit test keeps the page and the code together. It reads the C names from the headers that meson install places, and the Python names from the imported package. It fails when a public name has no entry, when an entry names a symbol that does not exist, when a Python signature row differs from the one inspect reports, and when a row that must say something is empty. The other reference pages explain the behaviour at more length: the C ABI reference, the Python reference, the GROMACS page and the LAMMPS page.

Conventions¶

Units are stated in every entry. The array calls of the C library take positions in Angstrom and give Hartree and Hartree/Bohr. cpmdc_session_calculate_au() takes Bohr and gives Hartree, Hartree/Bohr and a virial -dE/d(strain) in Hartree. The stress of the C library has the OpenCPMD sign -(1/V) dE/d(strain) in Hartree/Bohr3, which is the opposite of ASE’s. The Python Potential and the ASE calculator return eV, eV/Angstrom and eV/Angstrom3 with the ASE sign. Session returns the atomic units of the C ABI.

Arrays are C order and atom-major: x0 y0 z0 x1 .... A matrix is row-major with one lattice vector per row, except in the i-PI wire, where the cell holds the lattice vectors as columns. Atomic numbers are int values in 1..118.

Threads: the C library keeps the active calculator, its stored orbitals and the OpenCPMD state in process globals, so evaluation, configuration and session calls are used by one thread at a time. The error text of cpmdc_last_error() is per thread. The snapshot readers share the globals of the evaluation. The static restart library has no global state.

MPI: a build compiled without MPI never calls it. A reference build compiled with MPI calls MPI_Allreduce from rank_consensus_all on the session cache path when CPMDC_RANK_CONSENSUS is 1 and MPI is initialized, so every rank agrees before a stored result is returned. The same setting runs the collectives in rank_consensus on an evaluation. An OpenCPMD build also runs the evaluation as a collective on the calculator communicator, so every rank of a calculator makes the same call in the same order. The Python package never calls MPI itself; cpmdc.lammps.FixExternal gathers on rank 0 with mpi4py.

Errors: a C call reports failure in the return value and writes the reason to cpmdc_last_error() of the calling thread. The Python package turns every such failure into cpmdc.CPMDCError, and it raises ValueError or TypeError for an argument that it can reject before the call.

MPI calculator binding¶

Calls that choose the communicator of one calculator. See the MPI how-to for the sequence.

cpmdc_bind_calculator¶

Item

Description

Units

none

Layout

none: ranks_per_calc is a rank count; the world is split into consecutive blocks of that size, group g holding world ranks g * ranks_per_calc to (g + 1) * ranks_per_calc - 1.

Ownership

none: the library keeps the new communicator and the caller cannot free it.

Threads and MPI

Not thread-safe: call from one thread, before the first evaluation. MPI: collective on MPI_COMM_WORLD; on an OpenCPMD build it initialises MPI when it is not running, and the reference build and the link stub never call MPI; it splits the world with MPI_Comm_split; every rank passes the same value.

Returns and errors

Returns this rank’s calculator index world_rank / ranks_per_calc, 0 or more; -1 when the world size is not a multiple of ranks_per_calc (no remainder group is made, nothing is split, and every rank gets -1), MPI_Comm_split returns an error, or the library has no CPMD backend (the reference build and the link stub always return -1); the text is cpmdc_last_error(). A second call does not split again; it checks its own ranks_per_calc as the first call does, returns the index that value gives, or returns -1 on every rank when the value does not divide the world size or is above it, and the existing split stays.

Python

not wrapped; use cpmdc.lammps.FixExternal or the host’s own communicator.

Defaults

ranks_per_calc zero or less takes the whole world as one calculator

cpmdc_adopt_calculator_comm¶

Item

Description

Units

none

Layout

comm points at one MPI_Comm of exactly comm_bytes bytes (the size of MPI_Comm in the host’s MPI); ranks_per_calc is a rank count.

Ownership

comm is borrowed: the library copies the handle, does not call MPI_Comm_dup, and the caller keeps the communicator alive until the last session is destroyed or a later adopt replaces it. The caller owns comm and the library never frees it.

Threads and MPI

Not thread-safe: call, cpmdc_session_create() and cpmdc_session_destroy() from one thread. MPI: collective on comm; does not call MPI_Init or MPI_Comm_split; the group must be one aligned block of world ranks, and every rank of it passes the same ranks_per_calc.

Returns and errors

Returns the calculator index (0 or more); -1 when comm is NULL, comm_bytes is not the size of MPI_Comm, MPI is not initialized, the build has no MPI, the size differs from a positive ranks_per_calc, the group is not an aligned block, or a rank of the group has a live session that has evaluated; the text is cpmdc_last_error(). On -1 the stored communicator is unchanged.

Python

cpmdc.CPMDCError in cpmdc.lammps.FixExternal, which adopts MPI_COMM_SELF on rank 0.

Defaults

ranks_per_calc zero or less skips the size check

session_accept_topology fixes the topology only after an evaluation call passes its argument checks and collective orbital preflight. cpmdc.lammps.FixExternal¶

Item

Description

Signature

FixExternal(lmp, params, elements, *, fix_id='cpmdc', create=True, library=None, comm=None)

Units

The LAMMPS unit style of the run: metal (Angstrom, eV), real (Angstrom, kcal/mol) or electron (Bohr, Hartree).

Shape and dtype

lmp a lammps.lammps object with box, atoms and masses; elements one symbol or atomic number per atom type; atom IDs must be positive and unique but may have gaps.

Ownership and threads

Owns the session on world rank 0 and the fixes it creates, removed by close() or by leaving a with block (it is a context manager). lmp and comm are borrowed. Not thread-safe: LAMMPS calls back from one thread. MPI: with more than one rank every rank constructs the object and calls run; rank 0 adopts MPI_COMM_SELF and evaluates, and mpi4py is needed.

Raises

ValueError for an unsupported unit style, a wrong number of elements, an unknown element, or a partly periodic box; CPMDCError when the session cannot be opened, mpi4py is missing on several ranks, or comm has the wrong size.

Defaults

fix_id is 'cpmdc', create is True, library is None, comm is None (MPI.COMM_WORLD).
