Plane-wave scaffold reference¶

The plane-wave scaffold is declared in include/cpmdc_pwscale.h and implemented in src/cpmdc_pwscale.c (CPU and MPI), src/cpmdc_pwscale_cuda.cu (CUDA), and src/cpmdc_pwscale_cuda_stub.c (the CUDA calls of a build without CUDA). It evaluates one structure-factor sum on a synthetic plane-wave grid so that threads, ranks, and a GPU can be timed and compared on the same arithmetic. It is separate from the embed force call and the reference potential, and sits outside the C ABI of libcpmdc (see the C ABI reference): the functions use plain C linkage, the header stays in include/ and is used from the source tree, and libcpmdc exports only the functions of cpmdc.h and cpmdc_features.h. The rank how-to shows how to time it.

Availability¶

The scaffold is off in the default build. -Dwith_pwscale=true builds libcpmdc_pwscale.a, a static library that is not installed, together with the cpmdc-pwscale harness and the pwscale test suite; it needs OpenMP. Programs of the source tree include cpmdc_pwscale.h and link that archive. All functions have C linkage, and the header compiles as C and as C++. None of them writes cpmdc_last_error(); the return code is the whole report.

The sum that is evaluated¶

A problem has natoms atoms in a cubic cell of edge cell_bohr and npw plane waves. Let n be the smallest odd integer with n^3 >= npw. Plane wave k, for 0 <= k < npw, has the integer indices ix = k mod n - n/2, iy = (k / n) mod n - n/2, and iz = k / n^2 - n/2 (integer division), and the wave vector G = 2 pi / cell_bohr * (ix, iy, iz) in inverse Bohr. So the plane waves are the first npw cells of an n by n by n box, x running fastest; the box is cut short when npw is not a cube. With G2 = |G|^2 and the position r of an atom of atomic number Z:

w(G)     = 4 pi / G2 * exp(-G2 / (4 alpha)) * exp(-G2 / (2 sigma^2))
energy   = sum over G != 0, atoms a:  Z_a * w(G) * cos(G . r_a)
force_a  = sum over G != 0:           Z_a * w(G) * sin(G . r_a) * G

The term G = 0 is visited and adds nothing. It is visited only when the box that npw cuts holds the origin. With G in inverse Bohr, alpha is in inverse Bohr squared and sigma in inverse Bohr; the code does not check units.

How work is split¶

CPMDC_PWSCALE_DIST_PW gives each worker a contiguous run of plane waves and every atom; CPMDC_PWSCALE_DIST_ATOMS gives each worker every plane wave and a contiguous run of atoms. Piece i of p over m items covers [i * m / p, (i + 1) * m / p). Workers are the OpenMP threads of one call, and in the MPI calls the ranks of the communicator, each with its own OpenMP team. With the plane-wave split every thread keeps a private force vector, and the vectors are summed in thread order. With the atom split threads write disjoint force entries.

Agreement¶

A parallel or MPI result agrees with the serial one when cpmdc_pwscale_within accepts the energy and every force component, with the tolerance CPMDC_PWSCALE_RTOL, and the visit counts are equal. Bitwise equality is claimed only in the case below. For a fixed rank count and thread count, every rank holds the same bytes and repeated runs give the same bytes, because the partial sums are added in rank order and thread order. The CUDA path adds with atomicAdd on doubles, so its sum order is not fixed.

cpmdc_pwscale_within¶

Returns 1 when |got - ref| <= CPMDC_PWSCALE_RTOL * max(1, |got|, |ref|), else 0. The scale is the larger magnitude of the two values and never below 1. A NaN in either argument returns 0.

cpmdc_pwscale_eval_mpi¶

Evaluates the sum on every rank of one communicator and gives every rank the whole result. It binds a problem, runs one bound call, and frees the binding, on every call. It is the one-shot form of Binding.

The call is collective over the communicator. Every rank receives the partials of every rank and adds them in rank order, so every rank ends with the same bytes. stats->seconds runs from the entry of the bound call to the end of the rank-ordered sum, the Allgather included; the binding step before it is not timed. stats->alloc_bytes holds (ranks + 1) * (3 * natoms + 4) doubles of exchange buffers plus the scratch of this rank’s team.

Returns CPMDC_PWSCALE_OK, CPMDC_PWSCALE_ERR_NOMPI in a build without MPI (with stats zeroed), or CPMDC_PWSCALE_ERR_ARG. The pointers and the problem are checked on the calling rank before any collective, so a rank that fails that check returns at once without joining. If every rank passes the same bad argument, every rank returns CPMDC_PWSCALE_ERR_ARG; if only some ranks do, the others wait in the collective of the binding step. A caller whose ranks can fail on their own binds first and uses the bound call, which reports such a failure on every rank.

Binding¶

A binding holds a copy of the problem, dist, the rank and size of the communicator, the handle of the communicator, and the buffers of the exchange ((ranks + 1) * (3 * natoms + 4) doubles). It saves the checks and allocation of cpmdc_pwscale_eval_mpi on every step. The caller owns a binding from a successful cpmdc_pwscale_mpi_bind_create until cpmdc_pwscale_mpi_bind_free. The communicator is not copied, only its handle, so it must outlive the binding. The bound calls overwrite the buffers of the binding, so one binding serves one call at a time.

cpmdc_pwscale_mpi_bind_create¶

Binds a problem to a communicator.

Argument

Direction

Contract

prob

in

the problem, the same on every rank; copied

dist

in

CPMDC_PWSCALE_DIST_PW or CPMDC_PWSCALE_DIST_ATOMS, the same on every rank

comm, comm_bytes

in

as for cpmdc_pwscale_eval_mpi

out

out

receives the binding, or NULL on every failure

The call is collective: it runs one MPI_Allreduce that checks that every rank holds a valid problem and buffers, and that npw, natoms, and dist match across ranks. cell_bohr, alpha, and sigma must match as well, but they are not compared. On failure after that collective every rank returns CPMDC_PWSCALE_ERR_ARG and \*out is NULL. Three failures come before the collective and do not join it: out is NULL, comm_bytes differs from sizeof(MPI_Comm) for a non-NULL comm, and a rank or size query of the communicator fails. A build without MPI returns CPMDC_PWSCALE_ERR_NOMPI and sets \*out to NULL when out is not NULL.

cpmdc_pwscale_eval_mpi_bound¶

One force call on a binding. It has the arguments and the result of cpmdc_pwscale_eval_mpi for the problem and dist of the binding, without prob, dist, comm, and comm_bytes. The geometry arrays are per call.

The call is collective over the bound communicator and runs one MPI_Allgather of each rank’s return code, visit counts, energy, and forces. A failure on one rank, such as a missing array, a team that fails, or nthreads above 4096, is seen by every rank, and every rank returns the lowest (most negative) code any rank produced; forces_h_bohr is untouched then. A NULL bind returns CPMDC_PWSCALE_ERR_ARG at once, without the collective. A build without MPI returns CPMDC_PWSCALE_ERR_NOMPI and zeroes stats.

stats->g_visited is npw with either split, stats->atom_visits is the sum over ranks, stats->workers is this rank’s team, and stats->mpi_ranks is the communicator size.

cpmdc_pwscale_mpi_bind_free¶

Releases a binding and its buffers. The call is local and not collective, and it leaves the communicator alone. A NULL pointer is accepted and does nothing. The pointer is invalid afterwards. Without MPI the function does nothing.

cpmdc_pwscale_cuda_compiled¶

Returns 1 when the build compiled src/cpmdc_pwscale_cuda.cu, else 0. It does not look for a device.

When
