C ABI reference¶

The public C ABI (application binary interface) of libcpmdc is declared in include/cpmdc.h and include/cpmdc_features.h, with the export mark in include/cpmdc_export.h. include/cpmdc_restart.h declares the separate libcpmdc_restart (see RESTART file library). include/cpmdc_pwscale.h declares the opt-in plane-wave scaffold, which is not part of this ABI; its contract is in the plane-wave scaffold reference. Installed headers live under include/cpmdc/; include them as #include <cpmdc.h> with the flags of pkg-config --cflags cpmdc. Every function has C linkage, and the header compiles as C and as C++. libcpmdc exports those 52 functions and no other symbol; the exported symbols section below gives the mechanism. schema/inventory/surface_map_abi.txt records them; it is generated from the built library, and the c-abi-inventory test fails when the headers, the library, and the file disagree (see the surface map). The header records the ABI generation once, as CPMDC_ABI_VERSION; no function carries its own @since generation. The header comments, which the documentation site renders as the generated API pages, carry the declarations; this page adds the units, the return conventions, and the behaviour that the implementation in src/cpmdc.c gives each call. The API contracts page lists every function, type, and constant with its units, layout, ownership, thread and MPI behaviour, errors, and defaults; the reference-audit test keeps it in step with the headers.

Exported symbols¶

Every function of cpmdc.h and cpmdc_features.h is declared with CPMDC_API from include/cpmdc_export.h, and libcpmdc is compiled with hidden visibility (Meson gnu_symbol_visibility: 'hidden'). A function without the mark stays inside the library.

Compiler and macro

GCC or Clang

__attribute__((visibility("default")))

Windows, CPMDC_BUILDING_LIBRARY defined

__declspec(dllexport)

Windows, CPMDC_STATIC defined

empty

Windows, neither

__declspec(dllimport)

The library build defines CPMDC_BUILDING_LIBRARY. A host that links the shared library defines neither macro. Code that compiles the cpmdc sources or links a static archive defines CPMDC_STATIC, as every in-tree test does.

gfortran does not apply -fvisibility to Fortran procedures, so the BIND(C) glue in src/cpmd_embed_c_api.F90 and src/cpmdc_embed_apply_params.f90 would still be exported, as would the symbols of the static archives linked into the library (c-capnproto, capnp-fortran, minimage, and libcpmd.a). The build therefore also links with an export list that scripts/abi_inventory.py writes from the same CPMDC_API declarations: a version script with local: * for an ELF linker (ld.bfd, gold, lld, mold), and -exported_symbols_list for ld64 on macOS. The list adds no symbol the attribute does not mark: a hidden symbol stays hidden whatever the list says. The version script names no version node, so the exported names carry no symbol version.

An ELF version script and an ld64 export list do not treat a missing literal name the same way. A global: pattern exports a symbol when the link defines it, and does not require the symbol to exist. -exported_symbols_list requires every literal name to be defined, reporting an absent literal as an undefined symbol, while a wildcard entry matches only symbols the link defines. Every MPI Fortran sentinel is therefore written as a wildcard pattern so neither Open MPI nor MPICH leaves required undefined names for the other implementation. The version script always names them; the macOS list adds them when OpenCPMD is linked, and the serial macOS library lists the literal public cpmdc_ functions alone.

Releases up to and including 0.4.0 also export 56 internal functions with the cpmdc_ prefix: the glue between src/cpmdc.c, the parameter renderer, and the Fortran embed. No installed header declared them, so they were never part of the ABI, and hiding them changes no public function, CPMDC_ABI_VERSION, or the soversion. The tests that call them link a static archive of the library sources or the sources directly; the Python package loads only public functions.

The bytes can come from pycapnp, a memory-mapped file, rgpot, or any other Cap’n Proto binding that writes the standard flat stream format. ForceInput unit strings are matched without regard to case. Length: angstrom, angstroms, a, aa, bohr, au, a.u., atomic, nm, nanometer. Energy: hartree, ha, au, a.u., ev, electronvolt, ry, rydberg, kj/mol, kjmol, kcal/mol, kcalmol. The schema defaults are angstrom and eV; a unit set to the empty string reads as angstrom or hartree. ForceInput.box is empty or nine values, a row-major 3 by 3 cell in lengthUnit, one lattice vector per row. The caller’s box is the cell. A non-zero ForceInput.box replaces every CELL line of &SYSTEM and its SYMMETRY: a cubic deck and a cubic box keep SYMMETRY 1, another orthorhombic box gets SYMMETRY 8 and CELL a b/a c/a, and a box with off-diagonal components gets CELL VECTORS without SYMMETRY, which CPMD refuses beside it. An isolated deck (SYMMETRY 0, the default deck) keeps SYMMETRY 0 and takes only an orthorhombic box with positive diagonal entries; a box with off-diagonal entries fails with an isolated deck (SYMMETRY 0) needs an orthorhombic box, and one with a non-positive diagonal fails with the ForceInput box has a non-positive diagonal. Before fixing the session topology, a non-zero box converted to Angstrom is checked by one-sided Jacobi singular values and scaled LU with partial pivoting on a power-of-two scaled copy: a non-finite component fails with cell contains a non-finite component, a cell whose singular values do not all exceed the largest singular value times 3 times DBL_EPSILON (or whose scaled LU determinant is zero) fails with cell does not have three independent vectors, and a full-rank cell whose Angstrom volume falls below the normal binary64 range fails with cell volume is too small for binary64. Deck rendering also rejects a non-zero cell without a representable rank-3 volume (the periodic cell does not have a representable rank-3 volume or the cell does not have a representable rank-3 volume). Without ANGSTROM the box goes in as Bohr. An all-zero box is a system without a cell: the deck’s CELL stays, or a 12 Angstrom cube when the deck has none. The hasCharge, charge, hasMultiplicity, and multiplicity fields of ForceInput are not read by cpmdc.

CPMDCSession¶

An opaque handle. A session holds a copy of the CPMDParams bytes, the rendered deck, the topology, scratch arrays for step geometry, and the results of its last evaluation. session_accept_topology fixes the topology only after an evaluation call passes its argument checks and collective orbital preflight. A rejected preflight leaves the topology configurable.

A capabilities return of -1 is the size query.

MPI¶

Function

Behaviour

int cpmdc_bind_calculator(int ranks_per_calc)

collective on MPI_COMM_WORLD; splits the world into calculators of ranks_per_calc consecutive ranks, group g holding world ranks g * ranks_per_calc to (g + 1) * ranks_per_calc - 1; the world size must be a multiple of ranks_per_calc, with no remainder group, and any other world size or a value above it returns -1 on every rank and splits nothing; ranks_per_calc <= 0 means the world size, one calculator; returns this rank’s calculator index world_rank / ranks_per_calc, or -1 when the world size is not a multiple, MPI_Comm_split returns an error, or the library has no CPMD backend; on an OpenCPMD build it calls MPI_Init when MPI is not running, and the reference build and the link stub return -1 without calling MPI; a later call does not split again and returns the index its own ranks_per_calc gives, or -1 on every rank when that value does not divide the world size or is above it, and the existing split stays

int cpmdc_adopt_calculator_comm(const void *comm, size_t nbytes, int ranks_per_calc)

collective on the caller’s communicator; reads rank and size from that communicator; does not call MPI_Init or MPI_Comm_split; when ranks_per_calc > 0 the adopted size must equal it, and a mismatch returns -1 with both numbers in cpmdc_last_error(); the group must be one aligned block of world ranks, and any other layout returns -1 on every rank; the calculator index is the lowest world rank of that block divided by the adopted size; indices are unique when every group has the same size, which the same ranks_per_calc > 0 on every rank enforces; the handle is borrowed, so the caller keeps ownership and does not free the communicator until the last session is destroyed or a later adopt replaces it; an OpenCPMD build stores the communicator as mp_comm_world; a later call replaces it when no live CPMDCSession has started an evaluation, and if any rank has a live session that has evaluated every rank returns -1; a session that has not evaluated does not block it; also returns -1 when the pointer is null, MPI is not initialized, or the build has no MPI

int cpmdc_adopted_comm(void *out, size_t nbytes)

copies the stored calculator communicator into out (on an OpenCPMD build, mp_comm_world); returns 0, or -1 when no communicator is stored; does not write cpmdc_last_error()

cpmdc_bind_calculator() splits at most once per process, so call it before the first evaluation. A later call does not split again. cpmdc_adopt_calculator_comm() may run again after every session has been destroyed. See running under mpirun.

Configuration without a session¶

These calls configure the process-wide state that the global array calls use.

Function

Behaviour

int cpmdc_params_method(const void *params, size_t size, CPMDCMethodInfo *out)

decode the effective functional, charge, and multiplicity without applying the deck; 0 or -1

int cpmdc_set_params(const void *params, size_t size)

decode CPMDParams, render the deck, apply it; 0 or -1

int cpmdc_configure(const void *config, size_t size)

resolve a PotentialConfig and apply the result like cpmdc_set_params(); 0 or -1

cpmdc_configure() takes the cpmd arm when it is set. With the arm unset, a common overlay (CommonMethodSpec) lowers into synthesized CPMDParams. The fields it lowers are the ones cpmdc_capabilities_result() lists: xcFunctionals, basisSet, planewaveCutoffEv, charge, hasCharge, spinMultiplicity, scfEnergyToleranceEv, scfMaxIterations, kMesh, smearing, vanDerWaalsMethod, and vanDerWaalsS6. scfEnergyToleranceEv fills both values of CONVERGENCE ORBITALS: the orbital threshold and the total-energy change between steps, which ends a smeared (free-energy) SCF once the energy settles. A set cpmd arm and a set common overlay are merged. The arm bytes stay. Both deck renderers and the configuration the embed records apply the same precedence to the functional, cutoff, charge, and multiplicity lines cpmdc writes. A value a typed field sets beats the overlay, and the overlay beats a schema default. A typed dft or system section beats the top-level field of the same name. A field that is omitted or holds its schema default (functional BLYP, cutoff 70 Ry, charge 0 with hasCharge false, multiplicity 1) is unset and does not replace the top-level arm or overlay value. So xcFunctionals fills a BLYP functional, planewaveCutoffEv fills a 70 Ry cutoff, charge fills a charge of 0 with hasCharge false, and spinMultiplicity fills a multiplicity of 1. A typed system charge of 0 with hasCharge false is unset; a non-zero system charge, and zero system.charge with system.hasCharge true, is explicit. planewaveCutoffEv is in eV and the deck cutoff is in Ry, so the merge divides by the Rydberg energy in eV (13.605693 eV). spinMultiplicity 0 is unset, and any other value, an explicit singlet included, is merged and checked like the other overlay scalars. An xcFunctionals list is mapped before that precedence, and an unmapped token is rejected for every arm functional. An opaque carrier is rendered as given and is not read back into the recorded functional, cutoff, charge, or multiplicity. So the carrier check runs for every set overlay field, whether or not a typed field also sets it, including zero charge with hasCharge true and an explicit singlet spinMultiplicity of 1. The overlay field is rejected when inputBlocks, a raw section, or a generic section opens the owning section (&DFT for xcFunctionals, &SYSTEM for the cutoff, charge, and multiplicity), when a set directive names DFT.FUNCTIONAL, SYSTEM.CUTOFF, SYSTEM.CHARGE, or SYSTEM.MULTIPLICITY, or when the directives list of the typed dft section holds FUNCTIONAL or that of the typed system section holds CUTOFF, CHARGE, or MULTIPLICITY. Without an overlay, a FUNCTIONAL directive in the typed dft section or a DFT.FUNCTIONAL set directive is rejected when the deck is rendered, because the rendered &DFT section already carries the functional. The same render rejects a CUTOFF, CHARGE, or MULTIPLICITY directive in the typed system section, and a SYSTEM.CUTOFF, SYSTEM.CHARGE, or SYSTEM.MULTIPLICITY set directive. CUTOFF is written on every deck, including the default 70 Ry. CHARGE is written only when it is not 0 and MULTIPLICITY only when it is greater than 1; an omitted line is the schema default the recorded configuration carries. Those directives are rejected for a default value and for any other value alike. A default leaves the directive as a value the recorded configuration does not carry, and any other value leaves two lines. The render does not keep one and drop the other. Fermi smearing is copied as FREE-ENERGY and TEMPERATURE ELECTRON when &CPMD sets no free-energy or electron-temperature control (including split TEMPERATURE and ELECTRON arguments in cpmd.directives or CPMD.TEMPERATURE set directives) and the arm has no raw or generic &CPMD block. vanDerWaalsS6 is copied into a vdwParams section whose s6 is unset. basisSet must be unset or "planewave". Next to the arm the call rejects kMesh, scfMaxIterations, scfEnergyToleranceEv, vanDerWaalsMethod, and relativityMethod, and also already-set smearing or s6, vanDerWaalsS6 without vdwParams, a non-plane-wave basisSet, and a negative or non-finite overlay scalar. With the arm unset, an overlay field without a CPMD lowering is rejected, including relativityMethod and a basisSet other than planewave. That overlay-only lowering also rejects vanDerWaalsS6 without vanDerWaalsMethod and a non-zero smearing.widthEv with kind = none. Every rejection leaves a cpmdc_last_error() that names its cause. An arm inputBlocks, inputSections, or directives list the merge cannot read is reported with the overlay field that needed it, as in charge cannot merge: the cpmd arm has an invalid inputBlocks list. A message with neither the arm nor an overlay applies nothing and returns 0.

Global array calls¶

Each call applies the message it is given like cpmdc_set_params() and then evaluates. cpmdc_set_params() detaches the process image without clearing the stored orbitals: a call whose functional, deck, cutoff, charge, multiplicity, atom count, and elemental composition match the latched basis, and whose step without a cell matches a latched state that also has no cell (CPMDC_CELL_IN_PLACE does not apply without a cell, because embed_cell_moves_in_place returns false when has_cell is 0), skips full CPMD setup. It starts the SCF from the stored orbitals when the geometry is within CPMDC_WARM_RMSD (default 0.15 Angstrom) of a stored geometry, and from the deck’s guess without full setup beyond that limit. Any other call runs full CPMD setup and starts from a cold SCF.

duplicate the converged orbitals of from_key, and the geometry they converged at, into to_key, replacing any previous copy; the selected key is unchanged; when to_key is selected its live store is replaced immediately, otherwise the live store is unchanged; selecting to_key afterwards starts from that copy; a donor whose last pass did not converge is refused, including a parked copy and a copy onto the same key; a copy that would park a new key past CPMDC_ORBITAL_SLOT_LIMIT returns -1, cpmdc_last_error() names that variable, and the copies already stored stay; every calculator rank names the same keys, the same rule cpmdc_session_select_orbitals() has; the reference build returns 0 because it has no orbital store, unless the limit is set to a value that is not a positive integer, which fails the call; the link stub returns -1, including a same key copy; -1 for a NULL session, before any evaluation, when from_key has no converged orbitals, or on backend copy failure

cpmdc_session_set_constant_cutoff() sets the constant-cutoff kinetic functional of Bernasconi et al. (1995), which CPMD applies as G2 + A [1 + erf((G2 - E0) / sigma)], with cutoff_ry as E0, height_ry as A, and width_ry as sigma, all in Ry. A height or width of 0 selects 50 times the deck cutoff, or E0 / 10. The stress then carries no Pulay stress; see relaxing a cell at a constant cutoff. The call returns -1 and writes cpmdc_last_error() when a value is not finite, when E0 + 2 sigma exceeds the deck cutoff, when the message gives &SYSTEM as raw text, or when it already sets system.constantCutoff; the session keeps its previous setting. It survives a later cpmdc_session_set_params(). The link stub returns -1.

session_accept_topology fixes the topology only after an evaluation call passes its argument checks and collective orbital preflight. A rejected preflight leaves the topology configurable. A later step with a different count or composition fails with topology change requires a new session before CPMD runs. A reordering of the same elements stays on the session. Coordinates, the cell, and units may change between steps. On an isolated OpenCPMD deck the atoms are moved to the middle of the deck’s cell before each evaluation and the net force is removed, so a rigid translation of every atom changes neither the energy nor the forces (see CPMDC_RECENTER in environment variables). An evaluation with the same positions returns the stored energy and forces. A session evaluated after another session in the same process reuses the stored orbitals when the functional, deck, cutoff, cell, charge, multiplicity, and elemental composition match. A different method or composition runs setup on the next evaluation (see wavefunction state).

Session steps in atomic units¶

Function

Output

int cpmdc_session_calculate_au(CPMDCSession *s, int n_atoms, const double *positions_bohr, const int *atomic_numbers, const double *cell_bohr, double *energy_h, double *forces_h_bohr, double *virial_h)

energy in Hartree, forces in Hartree/Bohr, the virial in Hartree; 0 or -1

This call takes a periodic cell without a Cap’n Proto message. Its arguments come in the order of cpmdc_session_energy_forces(): the atom count, the positions, then the atomic numbers. Every quantity is in atomic units.

Argument

Layout

positions_bohr

3 * n_atoms doubles, atom-major (x0 y0 z0 x1 ...), Bohr

atomic_numbers

n_atoms values in 1..118

cell_bohr

NULL, or nine doubles: row-major 3 by 3, one lattice vector per row (a_x a_y a_z b_x ...), Bohr

energy_h

one double, Hartree

forces_h_bohr

3 * n_atoms doubles, atom-major, Hartree/Bohr, -dE/dR

virial_h

NULL, or nine doubles, row-major, Hartree

cell_bohr follows the ForceInput.box rules above for the deck: NULL and an all-zero cell leave the deck’s CELL in place, and a cell with a non-zero entry replaces the deck’s CELL lines and SYMMETRY. The session still keeps an all-zero cell as a step with a cell. A repeat of a step with a NULL cell does not match a stored step with an all-zero cell, and the other way round. With OpenCPMD linked, stored orbitals follow the same rule: an all-zero cell starts from them only when the latched step had a cell equal to it, and NULL only when the latched step had none. The virial is W = -dE/d(strain), the strain derivative of the energy taken with the opposite sign, so a compressed cell whose energy falls on expansion has a positive diagonal. It equals |det(cell)| times the stress of cpmdc_session_last_stress() and of PotentialResult.stress, which is -(1/V) dE/d(strain) in Hartree/Bohr3. virial_h holds zeros when the cell is NULL and when the evaluation produced no stress, for example for an isolated deck or a cell of zeros. ASE’s stress is -W/V and i-PI’s virial is W.

Energy, forces, and stress are bit-for-bit those of cpmdc_session_calculate_result() for a ForceInput with lengthUnit bohr, energyUnit hartree, the same positions, and box equal to cell_bohr: both paths scale Bohr to Angstrom with the same factor and share the evaluation and the session’s cache. The topology and repeat-step rules of the session apply.

It returns -1 and sets cpmdc_last_error() for a NULL session (null session), n_atoms outside 1 to INT_MAX / 3 or a NULL required pointer (invalid arguments), a topology change, and a failed evaluation. For a non-zero cell_bohr, it fails before fixing the session topology with cell contains a non-finite component, cell does not have three independent vectors, or cell volume is too small for binary64 judged on the converted Angstrom cell; when virial_h is not NULL and cell_bohr is finite, a Bohr volume above DBL_MAX fails before evaluation with cell volume is too large for binary64, and any non-finite component of volume * stress after evaluation fails with virial is not finite. When virial_h is NULL, the reference evaluator still fails a non-zero periodic cell whose Bohr volume cannot be represented for stress (cell volume is too large for binary64 or cell volume is not representable for stress). On failure the output arrays are left unspecified. The stub archive libcpmdc_stub.a returns -1 with the stub message. tools/cpmdc_ipi.c is an i-PI client on this call (see the socket drivers). tools/lammps/pair_cpmdc.cpp, the LAMMPS pair_style cpmdc, and cpmdc.lammps call it once per force evaluation (see LAMMPS). tools/gromacs/cpmdc_gromacs.c, libcpmdc_gromacs, calls it once per MD step behind the libcp2k API of GROMACS’ QM/MM interface (see GROMACS).

The dipole getter returns 0 only when the linked OpenCPMD recomputed dipomod%moment%dmom from the converged wavefunction of this evaluation. The supported route is a periodic Gamma-point, non-broken-symmetry deck with DIPOLE DYNAMICS or PROP / DIPOLE MOMENT BERRY. An isolated deck, a k-point calculation, the reference evaluator, and a deck without either request leave the dipole invalid. A deck that sets DIPOLE DYNAMICS in &CPMD and KPOINTS in &SYSTEM is rejected before any evaluation, by cpmdc_session_create(), cpmdc_session_set_params(), and the calls that take parameters, because OpenCPMD stops in localize2 on it; cpmdc_last_error() names both keywords. OpenCPMD’s ddip%pdipole is not this molecular dipole: ddipo adds the ionic term to make pdipolt, then multiplies by the cell volume to set moment%dmom. Reading pdipole after wfopts without calling ddipo would return stale module state.

The stress snapshot is valid only when the tensor was computed for a periodic cell: OpenCPMD ran totstr (cntl%tpres, which requires a periodic cell and CPMDC_STRESS other than 0), or the reference evaluator filled the toy tensor for a periodic deck using scaled LU with partial pivoting on the cell in Bohr. Accepted near-singular periodic cells receive a valid stress tensor, while a non-zero periodic cell whose stress volume overflows or is not positive fails the evaluation instead of leaving valid unset. An isolated cell (symmetry 0, CLUSTER, or an isolated-molecule keyword, including Hockney) leaves valid unset even when the box volume is positive. CPMDC_STRESS=0 leaves it unset on a periodic cell as well.
