#+TITLE: Cost of an FFTW plan for each CPMD transform

OpenCPMD built on FFTW 3 (~-D__HAS_FFT_FFTW3~) calls ~mltfft_fftw~ with
~use_wisdom~ false for every batched 1-D transform: it creates an
~FFTW_ESTIMATE~ plan with ~fftw_plan_many_dft~, executes it once, and destroys
it.
The program below times that plan and its execution, and a plan made once with
~FFTW_MEASURE~, for N points and M transforms, contiguous (stride 1, distance N)
or strided (stride M, distance 1) on input, over 200 repetitions.
It ran on one core of the Intel Xeon virtual machine with 8 vCPUs that ran
the NPT records, with FFTW 3.3.11 from conda-forge and no other job.
The sizes are the 120, 126 and 128 point meshes that 32 waters took at a
100 Ry cutoff.
The numbers of transforms, 150, 900 and 1800, were picked by hand and not read
from CPMD.

#+begin_src c
/* Time FFTW plan creation and execution for batched 1-D transforms of the
   shapes CPMD's mltfft_fftw makes: n points, m transforms, contiguous or
   strided. */
#include <complex.h>
#include <fftw3.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

static double now(void) {
  struct timespec t;
  clock_gettime(CLOCK_MONOTONIC, &t);
  return t.tv_sec + 1e-9 * t.tv_nsec;
}

int main(int argc, char **argv) {
  int n = argc > 1 ? atoi(argv[1]) : 120;
  int m = argc > 2 ? atoi(argv[2]) : 1800;
  int strided = argc > 3 ? atoi(argv[3]) : 0;
  int reps = argc > 4 ? atoi(argv[4]) : 200;
  fftw_complex *a = fftw_malloc(sizeof(fftw_complex) * (size_t)n * m);
  fftw_complex *b = fftw_malloc(sizeof(fftw_complex) * (size_t)n * m);
  for (long i = 0; i < (long)n * m; i++) a[i] = (double)(i % 17) + I * (double)(i % 5);
  int istride = strided ? m : 1, idist = strided ? 1 : n;
  double t0 = now();
  for (int r = 0; r < reps; r++) {
    fftw_plan p = fftw_plan_many_dft(1, &n, m, a, &n, istride, idist, b, &n, 1, n, FFTW_FORWARD, FFTW_ESTIMATE);
    fftw_destroy_plan(p);
  }
  double plan_est = (now() - t0) / reps;
  fftw_plan pe = fftw_plan_many_dft(1, &n, m, a, &n, istride, idist, b, &n, 1, n, FFTW_FORWARD, FFTW_ESTIMATE);
  t0 = now();
  for (int r = 0; r < reps; r++) fftw_execute_dft(pe, a, b);
  double exec_est = (now() - t0) / reps;
  fftw_complex *sa = fftw_malloc(sizeof(fftw_complex) * (size_t)n * m);
  fftw_complex *sb = fftw_malloc(sizeof(fftw_complex) * (size_t)n * m);
  t0 = now();
  fftw_plan pm = fftw_plan_many_dft(1, &n, m, sa, &n, istride, idist, sb, &n, 1, n, FFTW_FORWARD, FFTW_MEASURE);
  double plan_meas = now() - t0;
  t0 = now();
  for (int r = 0; r < reps; r++) fftw_execute_dft(pm, a, b);
  double exec_meas = (now() - t0) / reps;
  printf("n %d m %d %s: ESTIMATE plan %.1f us exec %.1f us; MEASURE plan %.3f s exec %.1f us\n", n, m,
         strided ? "strided" : "contiguous", 1e6 * plan_est, 1e6 * exec_est, plan_meas, 1e6 * exec_meas);
  return 0;
}
#+end_src

The ~FFTW_ESTIMATE~ plan of each call costs 2.6 to 6.9 us against 17.3 to
630.0 us for its execution.
A ~FFTW_MEASURE~ plan executes from 19% faster (128 points, 900 strided) to
22% slower (128 points, 150 strided), and takes 0.026 to 0.097 s to make.
